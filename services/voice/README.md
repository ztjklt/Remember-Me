# Voice Service

Owner: 王昊宇 (`qingtian-4`). Phase 3 — PLANNED. See the [task brief](../../docs/team/03_WANGHAOYU_BACKEND_VOICE.md).

This directory will contain consent-gated audio quality assessment, clean segment selection, voice datasets, voice profiles, provider adapters, and TTS. Third-party audio must never enter a subject's voice dataset.

No provider is selected or claimed complete. Voice consent is separate from recording consent, and provider secrets stay server-side.

Inputs and outputs must conform to `packages/contracts`.
