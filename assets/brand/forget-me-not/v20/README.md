# Forget-me-not v20

Two transparent, AI-generated macro views: `bloom-cupped.png` and `bloom-side.png`. Generated on 2026-10-02 with built-in imagegen, using the existing v19 flower as reference. No external stock photography.

The side view includes a short photographic stalk. Its endpoint and each petal's camera focus are calibrated in `docs/mobile-ui/memory-garden/botanical-v20-model.js`; the SVG branch must meet that stalk rather than the centre of the bloom.

Exact prompts and provenance: [PROMPTS.md](../../../../docs/mobile-ui/nature/garden-v20/PROMPTS.md).

These raster views create visual depth; they are not freely rotatable 3D meshes. Native apps have not yet adopted these assets.
