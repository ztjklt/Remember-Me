# Photographic stem asset

`stem.png`: 1024 × 1536 RGBA, generated with built-in imagegen on 2026-10-02. [Prompts and source record](../../../../docs/mobile-ui/nature/garden-v21/PROMPTS.md).

The displayed plant has a cylindrical stalk, fine hairs, alternate leaves with fine veins, and two closed buds. It is an artistic generated asset, not a field specimen. Top attachment `(530, 40)`, base `(525, 1490)` are image-space coordinates. `botanical-v21.js` maps both endpoints with a similarity transform so leaves are not stretched flat. Background pixels retain alpha zero.

Used only by the local web prototype; native apps have not adopted this asset.
