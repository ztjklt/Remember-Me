注意：超图生成具体来说：
不要把这 8 类记忆直接画成 8 个节点互相连线，那样一定稀疏。正确做法是：把 8 类记忆拆成“原子记忆节点”，再以“句子/事件”为超边，把多个原子节点一次性连起来，最后叠加向量相似边、时间边、因果边、身份边、表达边，形成多层超图。 这样图会天然密集，而且关系有意义。
## 1. 总体结构：四层记忆图
```
录音层：Episode / Segment / Utterance
原子记忆层：事件、情绪、心理、滤镜、状态、环境、身份、表达
超边层：每句话/每个事件 = 一个多边关系超边
画像与图表层：8类画像、事件流程图、心情晴雨表、决策价值图、表达方式图
```
核心思想：  
Utterance（句子）不是节点，而是超边。  
一句话同时连接：事件、情绪、心理、滤镜、声学状态、环境、身份、表达等 10～20 个节点。  
这样 50 句话就能产生 500～1000 个节点、2000～5000 条边。
## 2. 节点设计：每类记忆至少拆 5～10 个子维度
| 记忆类型 | 原子节点示例 |
|---|---|
| 事件记忆 | 事件、人物、地点、时间、动作、原因、结果、冲突、目标 |
| 情绪记忆 | 情绪类别、效价、唤醒度、强度、置信度、情绪对象 |
| 心理记忆 | 心理状态、需求、动机、防御、转变、自我评价、认知冲突 |
| 滤镜记忆 | 滤镜名、色调、光影、饱和度、对比度、质感、时间范围 |
| 状态记忆 | 分贝、语速、气流、停顿、颤抖、叹息、笑声、呼吸 |
| 环境记忆 | 场景、环境音、他人声音、设备声、噪声、空间感 |
| 身份IP记忆 | 职业、角色、性格、偏好、价值观、目标、禁忌、口头禅 |
| 表达记忆 | 语气、句式、词汇、修辞、节奏、风格、习惯用语 |
再加上桥接节点：主题、人物、地点、价值、目标、冲突。  
这些节点会跨句子反复出现，把不同超边连起来。
## 3. 多边关系：用超边制造密度
每条录音片段生成一个 Utterance Hyperedge：
```
{ 句子, 事件, 情绪, 心理状态, 滤镜, 声学特征, 环境音, 身份侧面, 表达特征 }
```
例如：
> “今天开会时老板否了我的方案，我很焦虑，后来同事帮我梳理，我觉得有希望了。”
可生成：
• 超边 H1：{U1, 事件=方案被否, 人物=老板, 情绪=焦虑, 心理=自我怀疑, 滤镜=冷白, 状态=语速快/气流急, 环境=办公室键盘声, 身份=产品经理/重视认可, 表达=短句/叹气}

• 超边 H2：{U2, 事件=同事帮助, 情绪=缓解, 心理=希望, 滤镜=柔和, 状态=语速慢, 环境=咖啡机声, 身份=重视合作, 表达=“后来……”}

跨超边再连：
• 事件因果：方案被否 → 同事帮助

• 情绪转变：焦虑 → 缓解 → 希望

• 心理变化：自我怀疑 → 希望

• 价值驱动：重视认可 → 寻求支持

• 表达相似：短句 ↔ 叹气

这样图就不是几个点，而是一张有中心、有路径、有社区的网络。
## 4. 向量与边权：让关系可计算
每个节点存一个向量：
• 文本向量：BGE / text-embedding-3

• 音频向量：wav2vec / CLAP

• 情绪向量：Valence-Arousal-Dominance

• 身份向量：标签 embedding

• 表达向量：风格 embedding

边权公式可设计为：
```
w = 0.35*语义相似度
  + 0.20*同句共现
  + 0.15*时间邻近
  + 0.15*因果/规则
  + 0.10*类型亲和
  + 0.05*情绪一致
```
再乘时间衰减：`exp(-λ|t_i - t_j|)`。
对每个节点做 top-k 相似边，k 控制在 3～5，避免变成毛球。  
这样既有规则边，又有向量相似边，密度足够。
## 5. 可视化布局：让图看起来丰富但不乱
推荐布局：
• 中心：用户 / 本次录音 Episode

• 第一圈：8 大记忆维度扇区，不同颜色

• 第二圈：原子节点按维度分布

• 第三圈：桥接节点：人物、地点、主题、价值、目标

• 时间轴：从左到右或螺旋展开

• 超边：用半透明凸包多边形包住同一句的所有节点

• 社区：Louvain 着色，显示知识聚类

• 边：实线=直接，虚线=推断，箭头=因果，粗细=权重，颜色=关系类型

颜色建议：
• 事件蓝

• 情绪红

• 心理紫

• 滤镜黄

• 状态青

• 环境绿

• 身份橙

• 表达粉

形状：
• 圆=实体

• 方=事件

• 菱形=情绪

• 三角=状态

• 六边=表达

• 星形=价值/目标

交互：
• 点击节点：高亮所有关联超边和路径

• 时间播放：逐句点亮

• 维度过滤：只看情绪+心理+滤镜

• 钻取：从画像节点下钻到原子节点

• 图表联动：事件流程图、心情晴雨表、决策价值图、表达方式图都作为聚合节点连回关系图

## 6. 与 Graphs 界面联动
四个图表不要孤立：
• 事件流程图：从 Event 节点和因果边生成

• 心情晴雨表：从 Emotion + Psych + Filter 时间序列生成

• 决策和价值图：从 Decision + Value + Goal + Conflict 超边生成

• 表达方式图：从 Expression + Tone + Lexicon + Syntax 生成

每个图表节点都是聚合节点，点击可展开到原始句子和原子记忆。  
这样关系图既是底层数据，也是四个图表的导航入口。
## 7. 推荐技术栈
• ASR：Whisper

• 情感/声学：openSMILE、wav2vec2

• 环境音：PANNs、CLAP

• 实体/事件抽取：LLM + NER

• 图数据库：Neo4j / ArangoDB

• 向量库：Qdrant / Milvus / pgvector

• 前端：Sigma.js、Cytoscape.js、G6、3d-force-graph

• 布局：d3-force、fcose、cola

• 超边可视化：凸包、多边形、社区气泡

## 8. 目标密度参考
一段 5 分钟录音，约 50 句：
• 节点：500～1200

• 超边：50～150

• 普通边：2000～6000

• 社区：5～15

• 桥接节点：20～80

这样图会看起来“内容丰富、多边关系强”，而不是三点五点几条线。
一句话总结：  
以句子/事件为超边，把 8 类记忆拆成原子节点，再叠加向量相似边、时间因果边、身份价值边和图表聚合节点，就能画出密集、可交互、可下钻的记忆多边关系向量图。
