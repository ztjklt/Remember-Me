# iOS 旧聊天长期记忆

2026-10-13，Product / Integration Owner 直接授权，见 [提案](../architecture/twin-chat-memory-proposal.md)。后端基于含实时声音的 e6a1c6b；iOS 原工作区既有功能保留。

## 行为

近期20轮逐字上下文外，新增同 Actor / Subject 所有者旧聊天语义与文字召回，覆盖其他会话。原消息长期保留；单次最多12组旧聊天、10000字符，摘要最多1500字符，不宣称同时读完所有历史。摘要按当前检索结果生成并缓存，保留原消息编号；模型生成主题仅作导航，回答与语义复核仍看到原消息。回顾全部聊天时从时间跨度选取材料，属于有限概览。索引单次上限20000组，超过时明确失败，不悄悄退回最新20组。

所有读取及模型调用要求本人所有者、同账号空间及有效 CLOUD_TWIN。助理内容始终不是本人事实；失效的助理答案不能进入索引、摘要或输出。摘要不写入人物模型、Voice Dataset 或校准。画像仍由本人核对。

新增本人查看/搜索、关闭及清除入口。清除删派生向量与摘要并设置时间界限，旧原消息不会被重新索引；原聊天历史和独立确认的 IOS_TEXT 保留。来源变化清除摘要和索引缓存；调用期间撤权/清除不能发布结果。摘要故障时显式标 unavailable，仍可读取检索到的原消息。
