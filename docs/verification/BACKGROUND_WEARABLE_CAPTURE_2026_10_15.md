# 后台录音与录音豆验证，2026-10-15

产品负责人在当前会话授权后台采集、录音豆内容丰富记忆／人物模型、实时活动与灵动岛，以及「我的」设备图示，并提供 D3200 官方 SDK 与照片。实现边界见 [授权提案](../architecture/background-wearable-capture-2026-10-15.md)。

## 实现

- 用户前台开始手机录音后，切后台不再主动停止；配置音频后台模式，暂停／恢复、音频中断和耳机移除会更新实际状态。录音每 30 秒保存检查点，容许文件在录制时锁屏继续写入；重启从音频实际帧数恢复有效的未归档录音。
- 增加独立 WidgetKit / ActivityKit 扩展：锁屏、灵动岛展开／紧凑／最小状态，录音／暂停、来源、计时、点回录音页；90 秒未收到状态更新显示待确认。系统关闭实时活动时录音功能仍可使用。
- D3200 官方 iOS SDK V1.3.01 通过可替换适配器初始化、扫描、用户选择连接、实体确认绑定、状态／电量、暂停／恢复、读取完整文件。开始／停止使用实体按键，SDK 没有的能力不展示成可用按钮。
- “我的”显示用户提供的录音豆照片和生成的耳机图示；耳机来自系统当前音频路线，未连接不虚构状态或电量。素材完整提示见 [图示来源](DEVICE_ASSETS_2026_10_15.md)。
- 完整录音豆文件按 Actor / Subject 隔离，以内容校验、设备文件 ID 去重，拆成不超过 5 分钟／12 MB 的 WAV 小段并保留时间范围和来源。断网／上传失败保留本地文件；重试不自动补开已撤回用途。设备原文件保留；删除已导入录音不会因再次同步而复活。
- 复用 Capture / 转写／记忆／模型流程；只有有效声纹模板、当前识别授权与服务端匹配的本人片段能自动更新本人模型。未知、亲友、重叠和跨越多人范围的引用不能写入本人模型。撤回本次识别授权或模板授权会退出模型并使对应记忆待核对，原始录音保留。
- 新增 Owner 作用域 SDK 临时会话，厂商长期密钥只在后端。官方 CI HTTPS 认证，不跟随重定向，不回显厂商错误／密钥，不接收客户端伪造的匹配报告。
