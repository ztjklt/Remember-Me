## 证据范围

截图中的问题、回答与轮次均为本地测试输入；AudioTrack 检查使用一秒静音 PCM，证明播放游标和 UI 状态的关系，不证明扬声器听感。没有调用线上 ASR / LLM / TTS，没有访问真人录音和记忆。既有线上通话测试入口已适配新的字幕弹层，但本轮未执行线上连续通话测试。

这轮不能据此宣称 DeepSeek 回答质量提高、端到端延迟下降或 vivo 真机音频验收完成。改进范围是客户端界面、状态准确性、旧回调过滤与重复播放确认消息的消除。

## 使用检查

安装后进入「对话 → 语音聊聊」：连接后说一句，看到「正在想 → 准备播报 → 正在说」；点「我来说」或直接插话，旧音频应停止；回答结束后恢复「我在听」。再检查暂停/继续、右上角文字与依据，以及结束后麦克风释放。使用同一账号和空间，无需重新创建智能体。
