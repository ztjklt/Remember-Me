# 自适应采集与时序因果推理验收

本次实现沿用 PR #86 的完整软件闭环。实际完成的是可解释的采集决策和基于本人证据的时序归因，不把叙述材料当作客观因果识别实验，也不宣称长期拟真质量已经被证明。

## 采集决策

- 使用对称二元观测通道的互信息 I(H; answer)，计算预期信息增益 bits；可靠性来自 Beta(3,1) 起点与折扣回答效果。它是可检验的决策估计，不是实际人格保真率。
- 排序考虑信息增益、领域不确定性、问题重要性、时间紧迫性、预期回答时长及负担；有界探索避免永久锁死低回报领域。贪心选题降低同领域/同证据重复，正常每轮最多三个。
- 回答是否补上领域、贡献独立材料、澄清矛盾，形成可追溯反馈。每次回答一次试验，多片段不重复计数；效果按 30 天半衰期折扣。删除依据撤回统计。重要领域不能凭低质量回答被宣布“完成”。
- 一小时录音达到 12 分钟，或半小时完成四次引导/校准时停止建议；六分钟或两次引导后减少到一个问题。确认过的直接暂停句也暂停一小时。自由录音不受阻。
- iOS 增加按 Subject 保存的“休息 30 分钟”和恢复按钮；它是本机偏好。页面刷新不产生成功/失败样本；暂停不把待答题标成已答。休息后重新读取计划，保留仍有效的待答题 ID。
- 同领域薄弱证据/深化追问有 24 小时冷却；矛盾和校准问题仍可优先澄清。每条题目的私有 policy_snapshot 记录评分组成和证据基线。

这些疲劳阈值是可解释的负担预算，尚未通过长期真人研究标定，不能从录音响度或情绪词推断用户心理疲劳。

## 时序与归因

- 单一主 LLM 的反思 schema worker 同时生成可选关系：本人明确归因、否认归因、时间先后、相关伴随、待验证假说。断言及事件必须定位到当前本人精确证据；时间文本只能摘自原文。
- 事件日/月/年转换为带精度的区间；重叠区间不强行排序，未知及相对日期保留未知。录音时间与事件时间分开。知识截止视图只使用截止前、当前仍存活的证据，不复活被删除的材料。
- 校验反证、时间倒置、时间或因果循环、不同语境；有问题的关系保留为待澄清，不进入推理链。对应高价值澄清问题回流 Planner。
- 新记忆引用转为稳定 Memory ID；同一个 EVENT 中仅省略日期/“我”的完全等价引用可以归一，不用同义词模糊合并事件。
- 支持最多四跳、32 条路径的祖先查询，携带所有事件和关系原话证据、语境及最弱支持权重。多跳归因链标为推演；不把边权当作统计因果概率。
- Twin 检索补入链条完整证据，受现有八个候选/八个引用上限约束，不截断证据来伪造完整路径。模拟原因回答需要可用归因链及完整引用，并标注本人归因；无干预依据的反事实问题返回 UNKNOWN。
- iOS 事件/决策图展示当前重新验证的关系、事件时间、不同说法与原话入口；删除/纠正后不继续显示旧链。

统计因果效应、未知混杂的识别、未记录反事实的预测不能从这些回忆直接获得。本次没有实现或宣称这些能力；记录明确假说与追问，用新材料验证解释。

## 实际验证

- Backend 完整测试：276 passed；覆盖新迁移的全新建库、重复升级、模型匹配和 downgrade。最终评分基线散列调整另跑针对性回归。
- AI Core 完整测试：150 passed。
- iOS 模拟器：13 个 unit、3 个 UI 测试通过；无真机操作。
- 新策略测试覆盖互信息性质、评分逆转、半衰期、源删除、暂停确认、历史引用不触发暂停、休息恢复和重复刷新。
- 新图谱测试覆盖完整多跳证据、区间不确定性、反证、循环、时间倒置、语境隔离、纠正/删除、第三方/Subject 隔离、引用归一与反事实拒答。
- 最新三段合成中文录音 → 实际本地 Whisper → 固定文本确认 → 实际 DeepSeek → 实际 BGE → 图谱/Twin 的验收 11/11 通过，见 fixtures/CAUSAL_REASONING_SYNTHETIC_2026_10_08.json。固定文本确认是合成测试操作，不代表真人自然语音或 ASR 完全准确。
- 第一次真实模型复验遇到改写文字误标 ORIGINAL，被证据校验拒绝；加强完整 excerpt 提示后，既有闭环检查通过。随后扩展检查发现事件长/短引用未连链，修正保守归一后最新因果验收通过。中间失败没有记成成功。
- Backend CI 的旧音频观测失败由 runner 缺少 ffmpeg 引起，本次 workflow 增加显式安装；远程最终状态以 PR checks 为准。

仓库根目录运行合成真实模型验收（需本地 Whisper、BGE、say、ffmpeg，以及私有 AI 环境文件）：

```sh
services/backend/.venv/bin/python scripts/verify_full_agent_loop.py verify \
  --env-file /absolute/path/to/private-ai.env --causal-only \
  --output build/causal-reasoning-live
```

去掉 --causal-only 并加入 --causal-evaluation 可复验旧闭环加新增因果材料。脚本临时建库、使用合成人物和录音、结束时删除数据库并停止临时 AI 服务，不使用既有用户录音或真机麦克风。
