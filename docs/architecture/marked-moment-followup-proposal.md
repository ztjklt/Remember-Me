## 当前可核实的边界

- `apps/android/hardware-sdk-example/src/Soundcore1302Bridge.java` 有 `onDecodeFileMarkers` 回调，并复制数组给 `Events.markers`。它在 App source set 外，没有进入生产 App，也没有把标记写入 Episode。
- 回调存在不等于已证明偏移与解码后音频、ASR 时间段一致。当前 Evidence 的 span 是转写字符位置，不能当音频毫秒；也不能用说话速度估算位置。
- 原始 Opus 解码、完整 SDK 依赖和真实录音豆验收仍未完成。本提案不声明具备实时语音或硬件自动追问。

## 本 PR 实际交付

私有模块 `services/backend/app/marked_followup.py` 提供 `MarkerBinding` 与 `next_marked_question`。它不注册 HTTP 路由、不迁移数据库、不修改当前问答或 App，不接受 SDK 原始时间点。

输入复用 `AuthorizedSnapshot`：调用方依据数据库归属、当前本人权限和有效来源构建快照；快照对象本身不是鉴权器。`MarkerBinding` 仅表示未来适配器已经核对的 Episode 与原文引用/指纹，不能由客户端任意声明后直接采信。每个绑定最多 32 条引用是本原型的内部容量，并非冻结后的客户端合同。

核心只对完整、当前版本、属于同一 Episode 的 SUBJECT 来源提出一个可跳过的意义问题；指纹变化、撤权、删除、跨人物/录音或缺失一条来源均不产生该问题。第三方、AI 推断及书面校正不能伪装为已对齐的本人音频；校正后的重新绑定留给适配器和本人核对流程。

相同来源集合上的重复按键共享问题 ID；这只消除重复提醒，不声称自动识别了同一个生活事件。不同片段或不同录音是否同一事件仍复用既有 `same_event` 本人确认与 `event_support`。标记次数不增加真实性、独立支持数或人格置信度。

调用方提供从服务端状态得出的已回答、跳过或仍在稍后的问题 ID；不反复询问。全局资料变化需重新核对绑定，来源没变时保留原问题 ID。问题生成不调用模型、不复制原文进问题、不把材料中的指令当系统指令，也不自动确认理解。

## 正式接线建议与分工

1. **Android / 硬件适配器**：先完成真实文件解码、稳定录音身份和标记回调采集；由实际 SDK/设备验证偏移单位及基准。保留原始回执，不重新标注音频格式或猜测定位。没有可靠对齐时显示待本人定位；若先用 App 选原文试验，明确标注人工标记，不能冒称物理按钮通过。
2. **Product / Integration**：审阅最小新增关系：Actor/Subject、Episode/原音校验值、标记来源/位置、已核对的证据引用/指纹、失效状态与追问状态。新增持久化与共享请求字段需另行 Issue/批准；本 PR 不改任何 `integration-contract-v0.1*` 或 experimental 版本。
3. **Backend 核心接线**：根据可信时间段和本人核对定位完整原句及必要上下文，生成绑定；从 `effective_materials` 重取当前来源，不能读取原始全文复活已屏蔽的词句。处理前后复核归属、授权、来源版本；未能完整定位就等待核对，不绑定整个录音来假装准确。
4. **当前追问入口**：先保留未解决冲突，再考虑标记意义、亲友请求、故事时间。一次只展示一个可跳过的问题，不能中断自由录音。复用现有决定接口的能力；回答关联与完成状态需批准后扩展，不偷偷添加新的公共字段。
5. **更新理解**：补充回答形成新的本人 Episode，保留原音、机器稿与本人核对稿；模型只能提出带情境、支持与例外的候选。本人确认后再用于 Twin。不要把“旧杯子值得保留”扩展成“所有旧物都不丢”；新问题仍按 Original / Simulation / Unknown 的既有边界回答。

按钮表示“我在意这一刻”，不代表同意云端外发、分享给亲友或作出任何新承诺。保留原本未标记的录音与原问答方式；删除、撤权和校正仍遵循现有级联失效规则。

## 可验证演示与真实验收

建议演示：本人讲旧杯子并标记 → 核对标记对应原句 → 可选回答“因为父亲留给我的；普通破旧东西仍会扔” → 确认有条件的理解 → 在未见问题“搬家要不要保留旧物？”中区分纪念物与普通物品，并显示对应原音/补充证据。它是计划样例，不是已执行的真人结果。

离线核心测试覆盖：无标记、单问题、重复按键、引用次序、决定抑制、来源/版本改变、跨人物/录音、完整性、删除/撤权后的不可见来源、第三方与书面校正排除，以及材料指令隔离。测试输入是构造的有效引用，不证明硬件或毫秒对齐。

正式端到端还需验收：SDK 标记与真实原声位置；本人定位/拒绝/稍后；补充回答保存并关联；模型生成、本人确认、未见问句与改写问句；无关事实保留；删除后问题/理解/答案均失效。缺少这组结果前，APK 不宣传“标记闭环已完成”。

回滚本 PR 只移除未接线模块、测试与本文，无数据库、客户端或线上行为影响。
