# Twin 跨会话记忆、个人模型微调与复刻验证

2026-10-14，Product / Integration Owner 直接要求：自动带入上一通电话和旧文字聊天，并实现自动微调及可靠的复刻评分。此请求授权本轮语义／接口／内部持久化调整；既有原音、审核、人物归属和许可规则保留。

## 共享聊天记忆

新电话保持新 call_id、独立 parent chain、当前 turn 和结束状态，但开启旧聊天记忆时自动检索同 Actor / Subject 的以前电话和文字消息；不重新播放旧答案，不把旧助手自述当本人事实。关闭／清除记忆、撤权、来源失效及隔离继续生效。

## 自动微调

新增独立 MODEL_TRAINING 许可及本人开关。CLOUD_TWIN／VOICE 不自动授权训练。训练材料仅限本人核对的 SUBJECT／CALIBRATION 原文字与明确用途许可；他人资料、模型回答、未确认摘要不能作训练目标。数据按原来源组永久分成 train / validation / test，保留训练与验证清单，不能把相同录音的改写划入验证。

采用适配器化的本地 MLX LoRA，实际更新可训练权重；现有 DeepSeek 答题与来源复核保留。独立自动 Worker 从既有后端拉取获准任务，在 Apple Silicon 本机训练，模型下载不带用户资料，训练不上传 Hugging Face、不启用遥测。当前本机 16 GB 的小模型可用于工程和候选训练；不凭小模型成功宣称比原模型更像本人。

任务记录资料基准、模型版本、分组清单与真实失败／缺资料／训练器离线／训练中／待独立验证状态。生成与发布都复核许可和资料基准。撤权／关闭／删改来源后旧适配器不能生效，Worker 清理派生文件。新增数据满足阈值且存在可用训练器时自动入队；底层模型权重不因聊天次数直接修改。

训练损失下降只证明拟合效果。候选需要独立未见题上的本人盲评、事实与边界回归通过后才可晋级；未达到时保持原版本并显示原因。无合格数据和验证证据时，不启动真人训练或切换生产模型。

## 复刻验证

界面提供“复刻验证”而非假定已经复制完整人格。以新问题的事先锁定回答、本人后来核对的真实回答和本人分维度评审为依据，测量决策、理由、价值优先、情绪及表达的一致率；原话复述、模型自评分和参与训练／检索泄漏的答案不计。

正式汇总只采用服务端固定题库中精确绑定的不同情境题；自填题保留诊断，但不计可靠汇总。同题组、标点变体及规范化后相同本人回答合并计数。

显示独立样本量、来源／问题组、版本、置信区间、覆盖缺口与趋势；没有足够独立样本时数值为空、状态为资料不足。固定题记录服务端发布版本，更新预测逻辑或适配器后，旧发布版本的评估不混入当前成绩；旧验证原记录保留可查。整体数值只在每个必要维度都达到阈值时展示，明确是测试范围内的一致率，不是总体人格完成比例。自动分析仅诊断，不能替本人评审。测验本人答案保留在验证库，不自动进入训练或日常 RAG。

v0.9 新增个人学习状态／配置／任务及验证题／反馈形状；旧客户端与 v0.1–v0.8 保持兼容。本人 API 与内部训练器接口分开；内部训练凭据不进入移动端。迁移接续 0020，新增训练许可、偏好、任务、心跳及独立验证记录，不清空既有资料。首轮仅 iOS CloudBase 与现有 iOS 客户端，Android ECS 不随之变更。当前交付候选训练与验证接口；生产推理尚未接入个人适配器，晋级函数的单元验证不等于生产发布功能已完成。
