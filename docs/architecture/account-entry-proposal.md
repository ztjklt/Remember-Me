# 普通账号与移动端入口（2026-10-08）

用户要求安装后能使用，不再手填开发凭据。此兼容性提案按本次授权实施。

- 新增 `/api/v1/accounts/register`、`login`、`logout`。账号密码登录换取30天设备会话；原有 Actor 凭据和 iOS 配对保持兼容。
- 注册只新建空白人物空间，绝不认领历史空间。旧测试身份仍可从折叠的开发连接入口进入。
- 服务端 PBKDF2-HMAC-SHA256（600000轮，随机盐）；数据库只存密码导出值和会话令牌摘要。登录错误不区分账号不存在和密码错误。
- SQLite短事务记录账号/IP限速，不在密码计算期间持有写锁；登录、注册限速跨进程共享。公网账号入口强制HTTPS，本地回环可HTTP。
- 注册须由运营配置开启，默认仅开发/测试开启；暂不实现密码找回、邮箱验证和多因素认证，不宣称生产认证验收。
- Android会话通过AndroidKeyStore AES-GCM加密后保存，密码不保存。退出清除本机会话并撤销设备令牌；身份切换继续使用响应代际检查。
- 网页使用同源HttpOnly、SameSite=Strict会话Cookie，检查写请求Origin防CSRF；现有显式Bearer开发方式保留。
- 服务地址属于安装配置，不把供应商密钥放入APK。无部署目标前只交付明确标注的本机测试包，不能把ADB连接当作任意网络可用。
- 迁移0013追加账号、尝试记录和设备会话期限，不导入别的分支旧迁移编号。
