# Natural capture, start-action consent and dialogue reuse — v0.11

Product / Integration Owner amendment in this chat, 2026-10-15: starting recording confirms recording, cloud transcription and same-recording speaker identification. Remove repeated switches and compulsory spoken consent formulas. Speech/names must not block useful transcription or conversation. Reuse normal Twin dialogue for material previously requiring a separate recording.

Start buttons show a short purpose notice and record the actual action/time/policy; server grants stay separately scoped and revocable. This is product confirmation for this recording, not authentication or a grant of other people's accounts. No required recitation. Natural self-introductions and explicit name corrections can occur during the conversation; otherwise keep stable speaker numbers and continue. Invalid/missing diarization degrades to usable transcription with uncertainty rather than assigning invented identity/times. Existing v0.10 records remain readable; v0.11 definitions are additive.

Normal owner Twin voice calls can opt into dialogue capture with the same start action. Raw user statements become owner-scoped pending material with call/turn provenance, never assistant answers or verified personality evidence. Existing chat recall remains usable even if capture/preparation fails. Independently scoped RECORDING, SPEAKER_IDENTIFICATION and VOICE grants are transmitted behind the single action; old clients that omit capture stay on the old behavior.

The worker may collect a bounded microphone-only clip from a normal utterance when the backend advertises capture. It does not record room output or enable LiveKit observability recording. A clean mono clip, checked with the existing batch ASR adapter for one speaker and adequate speech, can prepare an absent personal voice profile in background using existing Voice adapters and grants. Mixed/uncertain/short audio is skipped and later normal speech may be used. Conversation continues using the chosen voice; a prepared personal voice is offered for subsequent use. No cloning third-party group originals, no replacement of an existing profile, no silent model activation. Stored source/grants can be revoked/deleted; delayed jobs recheck permissions before publish.
