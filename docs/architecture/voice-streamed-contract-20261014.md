# 连续语音 C 路线增量契约

用户已授权与同模型的标准、快速版本比较。本轮只在既有指定语音账号开放 `streamed`，普通文字和校准不改变。

- A `reviewed`：完整生成、独立语义审阅。B `fast`：完整生成，省去独立语义审阅。C `streamed`：微信真实 SSE；首个完整、经结构和来源检查的要点即可准备首句 TTS，完整回答及后端版本检查完成后放行声音。
- C 不把半句 JSON 或未确定的否定限定直接播出。首句准备不是已发表的答案；截断、失效、取消后丢弃。最终首句与准备文字不一致则重新合成。
- C 普通停顿 400 ms；A/B 800 ms；简明模式均 1400 ms。实际识别收尾以实测为准，慢速讲话可能需要简明模式。
- 每通话复用 TTS 连接。材料缓存仅限本通话，并以身份、空间、同意、检索模式、完整来源版本、可见录音集合校验；每轮读取副本，绝不缓存答案。撤权仍即时复核。
- Android 采集与测试注入共用 PCM/VAD/打断处理；测试音频仍须明确是注入，不声称实体麦克风或扬声器回声已验收。
- 视频保留原速与真实等待，记录输入结束、ASR final、answer_ready、AudioTrack 播放及插话时停止位置。旧轮次未播放的音频不能拼接到演示声音中。

目标约 2 秒，未达标按实际报告；不以控制语或预写回答计入模型回答时延。

实测 SSE 单独增益很小后，C 的来源问答增加一次有限的推测合成：检索命中中的首条本人原话先合成首句，与模型选段重叠；此时没有任何声音发给手机。模型完整结果、后端来源与权限检查全部通过，且最终首句逐字一致时才使用；否则取消并重新合成。仅限当前获授权的来源，不替模型决定答案，不为自由人物模拟预写回答。需要记录命中、额外合成和失败成本。

## 最终收敛

C 使用语音专用短提示词 `twin-voice-quotes-v1`，仍保留完整材料与来源选择校验。相比 B 的提示词不同，因此不能将全部耗时差归功于 SSE。

仅缓存本通话内完整合成成功的 PCM，按完全相同文字命中，最多8条且不超过2 MB；不缓存答案、不跨身份、不落盘，通话关闭即清空。未知、撤权、失败及部分生成不绕过播放检查。每次实际播放仍由新一轮模型结果和后端版本校验决定。

跨请求微信连接池在隔离及手机试验中遇到响应头超时；未确定根因，最终撤销这项实验。恢复按单次请求管理微信连接，TTS仍按通话管理。原始失败记录保留，不算快速成功样本。

测试录屏每50 ms记录AudioTrack已播放帧，按帧进度重建数字声音；保留句间等待，打断后未播出的PCM不进入视频。停声/可闻首声另用10 ms窗、RMS > 200定位，区别于网络首包和AudioTrack启动。没有实体麦克风或扬声器回采证据。
