# 后台录音、Soundcore Work 与实时活动

2026-10-15 Product / Integration Owner 在当前会话直接批准：后台录音，长期佩戴录音豆的录音纳入记忆／人物模型，实时活动与灵动岛状态，「我的」设备连接图示。并提供官方工具包，iOS 选择 v1.3.01（实际 SDK `V1.3.01` / D3200），不接入 Android 轨道。此授权替代此前仅限提案的 iOS 设备／后台切片限制，不包含全局唤醒词。

手机在前台由用户开始后可锁屏继续，暂停／中断／断开如实显示；实时活动失去更新显示待确认。停止即保存，原音加密保存在 App 容器。设备端录音由设备真实能力驱动，App 不把 SDK 不支持的开始／停止命令伪装可用。

官方 SDK 通过隔离适配器扫描、连接、接收状态、列出并取回录音文件。只导入完整且能解码的文件，保持设备来源、录制时间、文件 ID 和内容校验；按当前 Actor／Subject 隔离并去重，不删除硬件原文件。上传复用 Backend Capture；后台传输和长期佩戴需实际设备试验，不能用模拟状态声明已连接。

新增 Owner 作用域 SDK 临时会话端点；官方 app_id / app_key 仅在后端私密环境，通过官方 CI HTTPS 域名换临时 token 与签名 license。手机和仓库不保存该密钥。凭证仅用于用户当前的设备连接；并不授权将所有附近设备绑定。SDK 二进制由用户提供的工具包本地准备，不向公共仓库重新分发。

采集与云端处理继续记录独立用途。仅匹配本人声音的内容能自动丰富本人模型；亲友或未知声音保留来源和待核对状态，不能冒充本人训练。默认手机录音在无硬件时仍可用。
