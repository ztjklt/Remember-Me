# 双身份免登录演示（用户确认范围，2026-10-17）

内部演示包首次启动进入虚构人物陈守义本人；“我的 → 我的账号”可切换亲友体验。顶部一直显示当前身份。亲友默认进入对话，花田仅显示服务端授权内容；固定的“待开放”占位不表达私密故事的标题、数量或存在性。

## 会话与边界

- 后端 `POST /api/v1/accounts/demo-session` 只接受 `owner` / `relative`，由运维显式开启并配置两个虚构 Actor 和一个 Subject。默认关闭，不能传入任意账号或空间。使用现有 DeviceCredential，不把密码、模型密钥放入 APK。
- `GET /workbench/spaces` 附加服务端确认的 `demo_role` / `demo_subject_id`；现有授权、原音、托付领取检查不变。亲友不因为演示切换获得本人权限。
- 两种身份都是本次共享虚构演示，不是生产免认证登录。不要向演示空间写入真实私密资料；关闭入口会停止签发，既有设备会话仍按到期/管理员撤销规则处理。
- 切换先停止录音豆连接、语音与播放、作废旧请求并清空视图，再加载新会话。失败不回退到旧身份内容。加密保存当前会话，重开恢复；失效可无密码重新进入同一演示身份。
- 正式/debug 包默认不开启自动演示；内部包开启。0.16.7 内部演示包仅提供本人/亲友两个身份；首次升级清除旧账号选择和会话，再进入新的陈守义演示空间。普通构建保留手动账号路径。

## 验收

后端覆盖默认关闭、输入伪造、HTTPS/限流、配置错误、不同 Actor 会话、不影响其它设备、亲友读取范围及拒绝本人写入/私密原音。Android 实际启动、切换、恢复、顶部身份、录音入口与花田遮蔽通过独立模拟器验证并截图。沿用 DeepSeek + 小米 TTS、既有路线纸材料与核验，不用脚本答案代替模型回答。
