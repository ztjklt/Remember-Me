# 语音下一轮执行计划

用户于2026-10-14授权：提前检索、精简输入、试验Smart Turn；同三问实跑原速视频；用新提供的比赛网关比较模型速度与质量。生产默认不因某模型单次更快自动替换。未授权GitHub推送。

1. 固定当前三问与完整来源基线；比赛网关仅使用虚构已授权材料，记录首内容/完整JSON/有效来源/语义结果，密钥仅ignored私密文件与服务器受限目录。
2. 提前检索：临时ASR防抖、有限任务；只预取材料，不生成/发布答案。最终问题、身份、来源版本完全匹配才复用检索结果，变化必须重新检索；不因前缀相似丢掉后置否定。
3. 输入精简：只去重复表示和冗余结构；不得删来源原文、时间、归属、纠正、条件及反例。保留可逆展开测试和真实质量对照。
4. Smart Turn先离线对同音频、思考停顿及未完句检查；只有收益与误判符合要求才接入通话，不能把离线接口当上线能力。
5. 本地确定性回归 → ECS隔离候选 → 同模型同问实跑 → 受控切换 → Android原速三问+打断视频。所有失败留存；稳定两秒不达则如实说明。

接口兼容：旧文字/审阅/校准不变；C streamed内部优化，不改公开权限。比赛网关测试先隔离，不把供应商密钥或公网试验入口放进APK。

Pre-flight: 预取与正式查询共享按版本的资料缓存，需独立缓存键与线程清理；输入精简仅在C路径，不影响标准审阅；Smart Turn实验不改变生产ASR；网关比较不改变默认WeChat路由。
