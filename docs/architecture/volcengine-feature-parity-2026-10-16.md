# 火山通话功能恢复与心跳修正

2026-10-16，Product / Integration Owner 在当前会话直接要求检查再次中断，并明确「声音复刻和声纹识别都加回来，之前的功能都得要有」。本提案记录该批准，继续火山 RTC + ASR + 现有 Twin 的主线路，恢复既有声音和资料能力，保留独立许可、来源与删除语义。

## 实现范围

- 本人音色复用现有 CosyVoice profile、复刻、轮询和试听；新增火山作用域别名，样本仍由 Backend 提交给已使用的声音服务。本人模式关闭火山默认 TTS，Backend 仅为当前有效已核验答案流式输出个人 PCM，客户端用 RTC 本地混音播放器播放，纳入回声处理。默认模式继续火山默认 TTS。没有客户端厂商密钥或任意文本合成端点，不创建或购买新的火山音色。
- 火山 call 关联共享 VoiceCall 资料上下文（显式 transport=volcengine），复用既有后台声纹分段、本人/亲友区分、绿色姓名、仅本人原话记忆及清晰本人音色取样工作。关联不是创建 LiveKit 房间或启动旧 Worker。对话保存与声音识别仍要求 RECORDING、SPEAKER_IDENTIFICATION、VOICE 独立许可。录音中未知/亲友不会当作本人资料，声纹不作为登录凭据。
- 移动端从 SDK 内部采集的只读 16k mono PCM 回调保留最多 30 秒内存，按真实 RTC round 状态取段、上传当前 call 的原音；服务端用现有独立 ASR/声纹核验，客户端文字不能成为本人证据。静音、结束和换账号清空缓冲，挂断取消上传。长段超限标记不可完整核验，不用截断音频为整轮归属背书。
- 心跳保活与答案/声纹状态轮询分开；保活不获取模型回答的发布锁。短暂超时/5xx 在现有租约内有限重试，撤权、失效和过期立即停止，不恢复过期 call。记录无文本/身份/凭据的数字原因。原 30 分钟上限、15 秒租约和撤权/断线清理不放宽。
- 新 v2 schema 保留 v1 不变。新客户端通过 features=2 获取恢复能力；旧客户端继续默认声音能力，未声明的音频能力不会自动开启。不会仅以 true 开关代替实现。

## 验证

定向覆盖：保活无答案发布锁、瞬时/持续故障、过期不复活；个人音色匹配许可、UNKNOWN/旧轮/撤权停止；音频界限、跨账号/跨 call/重复原音拒绝、声纹姓名撤销、仅本人记忆、取样/复刻/试听；手机连续两轮、静默续聊、插话/静音/结束，保留真实未通过项。不能将合成样本和 HTTP 成功称为本人音色听感确认。

补充连续性：自动整理或更正资料导致旧答案失效时，持久退休该轮并发送 RTC interrupt，客户端同步停播；可继续下一轮。远端 interrupt 失败则仍关闭通话，不能继续播失效答案。该行为不允许复活已撤权/过期的通话。

运行补充：火山资料核验使用单个串行后台工作循环，与 RTC 清理/保活循环独立；原每分钟定时任务作为恢复。复用行级状态和租约，避免重启或定时重叠重复处理。个人 PCM 每 200ms 核对当前答案/许可，试听返回前再次完整核验；客户端挂断/插话/撤权会取消请求并清空本地播放。

发布隔离补充：无流量旧实例仍可能执行后台循环。新维护循环对其他用途版本的未过期通话不执行终止；过期租约仍清理，API 不接受用途不符的续租。同一用途版本的多实例使用 PostgreSQL 非阻塞 advisory lock 串行发送外部控制，避免两个实例晚到的 interrupt 波及新轮次。首次从旧实现迁移仍需核对并停止旧实例。
