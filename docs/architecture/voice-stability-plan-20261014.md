# 连续语音响应稳定性：本轮边界

用户授权查清8秒阻塞，修复重试与波动，比较更快API，同题重复测试和原速录像。不推送GitHub。

- 诊断只记录连接、TLS、请求发送、响应头、首正文、完整选择和失败阶段；不记录密钥、请求头或私人原文。
- 用同一ECS、同一冻结的七题虚构材料，保留年份纠正、否定、未知、追问。线上候选从当前发布目录复制，不叠加尚未证明收益的预取及压缩提示词。
- 并发备用请求出现429，取消该上线方向；原始失败记录保留。生产候选只采用串行恢复，首请求3秒未完成则关闭，再在8秒共享期限内重试，最多2次实际请求。429/认证错误立即停止，不叠加外层重试。用户插话取消全部工作。
- 每次使用完整相同的已授权输入。格式、来源、条件和版本检查不删减。失败不伪装UNKNOWN，不交付失败或取消的草稿。胜出结果通过完整来源检查后才能准备声音。
- 比赛网关模型仅隔离比较，给思考足够输出预算；不因单题快而替换生产模型。
- 确定性回归与隔离恢复验证后，候选受控升级；同一个Android包经公网HTTPS/WSS实跑，录像保留等待。模拟器音频注入不算实体麦克风、回声与耳机验收。
- 如果未达稳定2秒，明确写实际分布、失败和剩余瓶颈，不能以成功首包或最快一次替代全部结果。

实跑中发现固定音频窗口可能误判正常积压，新增持续补充额度的 PCM 计量，保留突发上限和持续速率约束。最终三次 Android 尝试两次完成、一次上游模型超时；并未达到稳定2秒。详见 `docs/agent-loop/VOICE_STABILITY_RESULTS_2026-10-14.md`，包括失败、内容缺口及原速录像。
