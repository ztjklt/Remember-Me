# 语音审核修复与本人音色验收

2026-10-16，Product / Integration Owner 在整体审核后明确要求“开始修改”。本修订授权已确认的语音缺陷修复、本人音色试听验收和重做，以及完整源码基线整理；不将训练候选自动晋级，不扩展尚未授权的 Android、硬件或 Legacy 阶段。

删除任务记录持久尝试次数与下次重试时间，以有界公平批次和任务租约处理未知创建及删除失败。撤权立即关闭访问；供应商确认删除前保留待删除状态，不能把未知创建当成已删除。

RTC 的短暂断开进入有界恢复，暂停麦克风、原音取样和个人音色播放。恢复事件须属于当前通话，并重新确认 Backend 租约才恢复输入；结束、撤权、持续失败和恢复超时终止通话。恢复不会延长既有通话有效期。

UNKNOWN 只朗读固定服务提示：“现有资料还不足以回答这个问题。你可以补充相关经历，或换个问题。”无论 UNKNOWN.answer 包含什么，都不能发送给 TTS；提示不成为人物原话、Episode 或训练证据。默认与本人模式保持相同的已保存答案／当前轮次／许可校验。

新增独立严格契约 voice-review-v1，不改变 v0.6 profile 或火山 v1/v2 JSON：

- GET `.../twin/voice/[volcengine/]profile/review` 返回当前音色 pending / accepted / rejected，或 missing，以及 profile_id、reviewed_at、previewed_at。
- POST 同一路径提交 `{profile_id, accepted}`。仅本人有效 VOICE 许可可提交；accepted 要求已就绪、模型与用途匹配且成功生成试听；拒绝立即结束该音色的进行中通话。
- POST `.../profile/retry` 明确选择当前音色后，停用旧音色、删除复刻专用样本并排入远端删除。保留独立 VOICE 许可、原录音、记忆、声纹；相同旧 ID 重试幂等，不能停用后续新音色。

供应商 ready 与本人 accepted 是不同状态。已有音色迁移为 pending，不伪造本人确认；仍可试听，确认后用于新通话。既有进行中通话不会因迁移 pending 被追溯挂断。iOS 不自动选用新就绪音色，默认声音继续可用。

本轮不要求本人立即通话。自动化验证只证明实现和约束，真实试听、噪声、多说话人、插话及持续通话结果另记。
