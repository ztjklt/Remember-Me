# 花园局部保护与底层删除提案

状态：待 Product / Integration Owner 批准。依据会议 §2.4 和已批准实施计划；基础浏览已交付，本文件不授权新的 Contract、迁移或发布。

## 现有能力与差距

Backend 基线为 codex/twin-chat-memory / fee7e5b，业务源码包括 54856ef。`services/backend/app/access.py:visible_episodes` 对 owner 返回所有 Episode；reader 按 StoryGrant 过滤。`sharing.py:preview` 将故事选择扩展为完整 Episode，公开完整原音和核对文字。`retrieval.py:retrieve` 的 reader 路径不复用 owner 的整体人物／图谱，已有授权和来源变更后发布检查。这些可复用，但不是局部密码保护。

iOS MemoryGarden 只保存本机展示编号。`api/person_model.py:delete_memory` 是 Memory 软删除，重算模型并使答案失效，保留 Episode 原音；`api/episodes.py` 没有整段来源 DELETE 路由。本轮不能把它称为彻底删除底层记忆库。

## 建议冻结的语义

1. 保护以 **完整 Episode** 为最小原始资源边界。第一批不承诺在完整原音里安全遮掉一句话。选定某朵花时预览它涉及的所有 Episode，以及这些来源还支持的其他花朵、人物、表达和答案。
2. protected 为资源权限属性，independent of 本机展示。保护后本人仍可在专门管理视图核对；本人和亲友的普通 Twin、普通搜索、普通花园都不使用受保护资源。指定对象仅在身份、资源授权及解锁条件全部满足后进入专属范围。
3. 密语只验证解锁条件，不创建账号、StoryGrant、声音许可或新权利。未获指定授权的 Actor 即使知道正确密语，也无内容、标题、关系、计数或存在性提示。
4. 设置保护必须处理现有整段分享：预览所有受影响授权；确认后原子撤销或限制相关授权，失效旧回答和音频引用，并终止正在使用材料的生成／通话。不能保留一个旧原音地址绕过新保护。旧客户端调用所有原路径也要受到服务端规则约束。
5. 解锁只针对一段短期会话和当前设备登录，不保存明文密语。建议 10 分钟、离开专属范围／锁屏／退出／撤权即失效；准确时限和错误次数规则由本提案批准时确认。响应只返回不透明句柄和到期时间，日志不含密语、音频或转写。

## 读取与生成必须共用范围

候选内部 AccessContext：actor、subject、operation、allowed_episode_ids、protection_revision、grant_revision、unlock_id、expires_at。服务端计算，不信任客户端提交的允许列表。所有读取先过滤，生成结束前再次核对；短发布事务沿用 publication_lock，模型调用不持锁。

| 路径 | 拦截与派生规则 |
| --- | --- |
| 花园／人物／故事／图谱 | 节点、关系和计数都从可访问来源计算；混合来源的已整理记录需要全部支持材料可见，否则整体隐藏 |
| 记忆／原话／原音／导出 | 检查同一范围；完整 Episode 内有保护时整体受限，旧音频 URL 不例外 |
| 关键词与向量检索 | 进入候选集之前过滤；embedding 命中不能解锁，排序、摘要与建议问题也不泄漏 |
| Person Model／表达范例 | 普通范围从未保护材料派生，不能读可能含秘密的 owner 汇总画像；用范围和模型版本标记缓存 |
| 聊天原消息／摘要／答案链 | 从引用及实际生成输入核对；曾使用受保护材料的旧轮、摘要和派生上下文全部失效，不只隐藏引用按钮 |
| Twin／实时声音 | 问答保存与每段音频输出核对范围；保护修订或撤权发生后旧输出立即停止，不重放 |
| 分享／邀请／恢复展示 | 展示不授予权限；邀请批准时重新核对范围与版本，不允许保护变动后的旧预览继续批准 |

仅为新素材加过滤仍不够：先前未保护时形成的摘要、画像、表达范例、聊天或缓存须重新派生或整体失效。语义无法证明不含保护材料时拒绝复用。

## 候选接口（不可当作现有接口调用）

候选命名置于 `/api/v1/subjects/{subject}/protection`；正式版本须在批准时确定，不能改写现有严格 schema。

| 操作 | 请求要点 | 响应与约束 |
| --- | --- | --- |
| POST /preview | episode_ids、目标保护设置 | impact_revision、资源／授权／衍生物范围；只有 owner 可查看 |
| PUT /regions/{id} | expected_revision、impact_revision、episode_ids、指定对象、密语设置 | 新 revision；冲突 409，任何一项无权时整批失败；密语不回显 |
| POST /regions/{id}/unlock | 当前登录、密语 | 不透明 unlock_id、expires_at；不能扩大 grant |
| DELETE /unlocks/{id} | 当前登录和句柄 | 幂等失效，关闭相关输出 |
| POST /deletions/preview | target_kind=memory 或 episode、target_ids | 删除／保留范围和短期确认句柄，绑定 owner 与版本 |
| POST /deletions/commit | 确认句柄、expected_revision、idempotency_key | 任务编号、状态和各阶段；重试不重复删除其他目标 |
| GET /deletions/{id} | 本人登录 | blocking_access / cleaning / completed / cleanup_failed；未清理完不能显示彻底删除成功 |

未来迁移需要保护资源／指定对象／短期解锁、删除任务及审计记录；沿用现有 Subject、Actor、StoryGrant、Evidence 标识。具体表与字段在实现批准后再冻结。未选择保护的旧资源保持现有行为；保护开关只在所有服务端路径覆盖、版本化用例通过后开放。

## 两种删除与失败恢复

- **移出展示**：本机编号可恢复；录音、文字、模型与分享权限不变。
- **删除一条整理记忆**：现有 Memory 删除；原文／原音仍保留。相同原话仍可能支持其他有效记录，界面明确告知。
- **彻底删除来源**：删除完整 Episode 原音、机器／核对文字、证据及派生材料；保留不含正文的任务与审计元数据。混合来源派生项失效或重算，关联声音样本／音色若存在须使其不可用并清理远端引用。

彻底删除先持久化禁止访问与停止运行任务，再异步删除对象存储、检索索引、模型派生、聊天／答案、音频及远端声音资产；记录失败并可重试。已下载或已听到的内容无法通过服务端撤权收回，产品应在分享预览说明。备份清理期限须在启用彻底删除前确定，不能在仍有可恢复副本时宣称即时物理清零。

## 验收用例（均待实现后运行）

| ID | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| PG01 | A 保护含两个故事的同一录音，B 用旧 grant／原音 URL | 两故事及原音均受限；旧客户端和完整文字路径也拒绝 |
| PG02 | 无授权 B 输入正确密语 | 不返回标题、节点、计数、音频、答案或解锁句柄 |
| PG03 | 普通 owner Twin 搜索保护前已生成的摘要／画像 | 无受保护事实、表达或暗示；旧混合派生项失效 |
| PG04 | 正确对象只解锁区域 X，问题追问区域 Y | Y 不进入检索／生成／音频；上一范围答案不能带入 |
| PG05 | 开始答案后保护／撤权／到期 | 生成、保存及播放停止，晚到结果不可发布 |
| PG06 | source 或 grant 改变后提交预览 | 409，整批无部分保护／部分撤权 |
| PG07 | 移出展示、取消删除、恢复 | 原音／原记忆不变；取消不调用删除 |
| PG08 | 删除 Memory | 原音保留、理解／答案失效、界面明确范围 |
| PG09 | 删除 Episode 时对象清理失败，再重试 | 内容已经不可读，状态 cleanup_failed；重试清理同一目标，完成后依赖均无可读正文 |
| PG10 | 猜测另一个 Subject 的区域／解锁／任务编号 | 拒绝且无跨空间元数据 |

批准点：整段 Episode 保护边界、普通 owner 问答排除规则、既有分享的迁移行为、解锁时限、彻底删除留存与新版本 Contract。实现顺序：统一权限过滤 → 旧派生失效 → 撤权竞态 → owner 管理 UI → 指定对象解锁；不先做仅页面保护。
