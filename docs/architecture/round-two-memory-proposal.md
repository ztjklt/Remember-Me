## 共享接口

新增 `/api/v1/workbench/subjects/{subject_id}/narrative`：overview、records、records/{id}、confirm/reject/undo、suggest、jobs、next-question、style。记录类型是 story/person/observation/letter/style；支持多条 evidence 引用、八个 facets、情境原文、本人审核和 revision 乐观锁。历史只向 owner 开放。

所有来源均从 effective_materials 解析，不能从原始全文复活已删除/纠正事实。记录间不形成另一套事实库。新增派生资源的已确认版本参与问答 source_basis；模型调用期间不持有写锁。
