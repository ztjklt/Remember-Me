# 主用户与亲友／游客双模式

状态：2026-10-16 Product / Integration Owner 在当前会话明确要求实施所确认的完整方案。本提案记录此次共享 Contract 授权。首版为 iOS 同机访问；Android 保持兼容，不启动跨设备邀请或互联网公开浏览。

同日追加要求：只有主用户模式保存文字与语音 Twin 对话；游客模式不做对话记录。游客问题、答案、转写与音频不得写入数据库、文件、聊天索引、摘要、本人资料或训练。为保持本次交流，服务端仅在进程内存中保留有界临时上下文，结束、到期或服务重启即丢失；会话授权元数据仍独立保存。客户端游客录音及播放均使用内存，不创建录音文件。现有 JSON 形状不变。

## 产品行为

- 主用户使用现有账号密码，日常可记住登录，拥有本人空间内的管理权限；原有录音、云端问答、声音和训练用途仍分别校验。
- 主用户可主动切换为亲友／游客。游客无需账号或密码，只能进入「记忆花园」「TwinAgent」，查看本人明确开放的资料，进行文字和语音交流。所有新增、修改、删除、采集、训练、校准、账号、设备、音色及托付管理均不可用。
- 游客切回主用户必须重新验证原账号密码。验证失败不升级权限。重启保持游客模式，不恢复游客聊天或主用户权限。
- 录音、通话或涉及资料写入的操作进行时不能切换模式。结束游客访问或成功切回主用户后，清理游客聊天、上下文及临时音频。

## 开放边界

本人选择来源后先预览，再确认开放。最小开放单位为完整 Episode：对应整段原音、核对文字及它关联的其他已核对记忆都在实际范围内，不能用一朵花的标题掩盖连带开放内容。新来源默认不开放；私密、受保护、删除或未经核对来源不得开放。修改来源后须重新确认。

花园、原音回放、检索、引用、对话上下文和语音输出使用同一服务端范围。不能将本人完整画像、旧聊天、其他私有来源或托付身份提供给游客。撤销、来源变更、删除及声音撤权须在生成发布和音频返回前再次检查；过期会话和旧答案不可继续使用。

游客问答不是本人证据。不得写入本人 Episode、Person Model、声纹、音色样本、校准或训练。默认声音可用；本人声音只在本人明确向游客开放、现有 VOICE 授权有效且本人已接受该音色时可用。游客语音输入只用于本次交流，独立确认当次录音与云端处理用途，不进入资料采集。

## 实现约束

新增独立游客访问上下文及版本化 `guest-access-v1` schema，保留既有 v0.1–v0.12 和现有账号接口。本人管理、设备入口凭据和临时游客会话三者用途分开；游客凭据不得通过 `current_actor`，不得借用本人 token 调用原有接口。

仅在本人登录并拥有该 Subject 时能配置开放范围并建立本机入口。设备入口是可撤销的随机能力凭据，只能创建受限游客会话，不出现在 URL；服务端仅存摘要。游客会话短期有效、独立隔离，使用现有 STT、Twin 和声音 adapters，不含供应商密钥。返回主用户通过服务端验证当前原账号密码，而不是比较客户端标记。

### 新增接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/subjects/{id}/guest-access` | 本人读取开放设置 |
| `POST .../guest-access/preview` | 用 `episode_ids` 预览完整来源，返回 `source_version` |
| `PUT .../guest-access` | 确认版本与来源列表、`enabled`、独立 `personal_voice_enabled`；拒绝过期预览 |
| `POST .../guest-access/device` | 为当前本人登录签发本机 `entry_token`；重签撤销旧入口 |
| `POST /api/v1/guest/sessions` | 用本机入口创建临时 `session_token`，无账号或密码 |
| `GET /api/v1/guest/session` | 当前人物、开放修订、过期时间、文字／语音能力及当次用途说明 |
| `DELETE /api/v1/guest/session` | 结束并清理本次游客访问 |
| `GET /api/v1/guest/memories` | 当前开放的整段核对文字和相关记忆 |
| `GET /api/v1/guest/episodes/{id}/audio` | 当前范围内的原音，响应禁止缓存 |
| `POST /api/v1/guest/questions` | `question`、可选 `request_id`／本会话 `previous_answer_id`；返回既有 Twin answer 形状 |
| `POST /api/v1/guest/spoken-question` | 当次确认用途的临时音频和会话父消息，返回 `{text, answer}` |
| `GET /api/v1/guest/speech/{answer_id}?voice_mode=default\|personal` | 当前会话的有效答案，返回 24 kHz 单声道 WAV |
| `POST /api/v1/accounts/reauth` | 用原本人凭据绑定账号，再验证 `{password}`；返回现有登录形状 |

游客会话状态包含 `personal_voice_available`、`default_voice_available`、`spoken_question_available`、`cloud_asr_policy` 与 `speech_notice`，服务不可用时明确声明能力。每次最多确认开放30段来源；文字来源返回 `has_audio=false`，不显示原音播放入口。音频输入为 multipart；不新增任意文本合成、声纹登记或训练端点。JSON 形状见 `packages/contracts/schemas/guest-access-v1.schema.json`，敏感响应均为 `Cache-Control: no-store`。

临时会话最长2小时；主动结束、密码复验成功、本人登出或开放范围变更会删除其对话。服务启动及每60秒清理到期／失效会话，处理客户端崩溃或离线无法发送结束请求的情况。本机入口绑定签发时的本人登录凭据，登出、密码重置及凭据过期后不能继续创建访问。游客返回主用户时如原登录已过期，可重新输入原账号密码，仍须校验同一个 Actor 和 Subject。

临时上下文仅属于当前服务进程，不使用数据库或持久化 Redis 恢复。每次交流最多保留128条回答，送入模型的前文仍受20轮／24000字限制；旧前文因重启或进程切换不可用时拒绝旧父消息，开始新对话后继续使用。多进程部署须配置会话亲和性。游客识别绕过录音任务的持久化检查点；需要供应商长时间保留上传音频的异步识别适配器不向游客声明语音提问能力。第三方同步服务的临时处理边界仍在当次用途说明中告知，不据此承诺供应商绝不留存。

## 验收

1. 本人原有流程保持可用，游客只有两个入口；深链、直接 API 和后台任务均不能绕过模式。
2. 预览显示全文、整段原音及连带记忆；未开放、其他人物、私密和未核对来源不进入花园或 Twin。
3. 连续游客问答与本人旧聊天、其他游客会话隔离，不改变本人模型或训练状态。
4. 来源修改、删除、撤销和声音撤权阻断旧答案、原音、语音及正在生成的晚到结果。
5. 错误密码不能返回主用户；重启保持游客权限；结束会话后旧凭据与旧上下文均失效。

实际执行的自动检查、构建及未执行的真机验证记录在本轮 verification 文档，不以模拟检查替代真实体验。
