# 对话回溯与专属信

产品请求（2026-10-17）：用户要求在有对应原因的对话下显示入口，打开旁侧的信笺并播放原音；人物统一陈守义。这是新增跨模块实现的范围依据。

本人明确把一封已发布的账号专属信关联到若干可见证据。只有本次已核验回答实际引用这些证据，且当前账号是本人或该信指定收件人，服务端才返回 `recall_actions`。不会让模型读取私信、推断收件人，或凭关键词宣称存在某段原因。新入口不添加 LLM 请求。资料变化后关联失效，需本人重新确认。

入口打开时重新验证回答、来源、信件发布状态、收件人及关联。原音按现有受限媒体接口读取；关闭、切后台、失去权限停止播放。公开答案与私信文字保持分开。账号专属信与联系方式验证码托付是两条不同的领取路径，后者的访客凭证不获得 Twin 权限。

信笺采用森林绿与暖纸色，展开正文自适应高度；播放器用实际音频时长，花瓣动效遵循减少动态效果。演示音频及人物材料标明虚构合成，不冒充真实人物原声。
