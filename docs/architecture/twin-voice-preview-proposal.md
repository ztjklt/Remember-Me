# 本人音色就绪与试听

2026-10-14，Product / Integration Owner 在当前聊天要求明显展示录音、复刻和通话前置状态，并确认如何知道本人音色已复刻好。该请求授权本次 iOS 状态界面及本人音色试听；沿用现有云端 Voice 许可、供应商适配器和 Actor / Subject 隔离。

新增 GET /api/v1/subjects/{subject_id}/twin/voice/profile/preview，以 audio/wav 返回当前就绪本人音色对固定试听句的合成音频。请求须本人登录、有效 VOICE、未撤销就绪音色、匹配当前模型及已接受的声音用途。无需额外 CLOUD_TWIN，因为不处理模型问答或记忆。固定试听句不是本人原话或人格证据，客户端明确标注合成音色试听；不保存为 Episode 或聊天，不在手机暴露供应商音色编号。

生成期间逐包及返回前检查原音色与许可；撤销或更换时拒绝交付已生成内容。试听音频有大小上限，响应禁止缓存。v0.6 / v0.7 JSON 形状保持不变，增加端点而不改变既有通话必需字段。未授权默认音色替代本人音色，本轮仍要求就绪的本人音色才能通话。
