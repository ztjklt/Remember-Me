# 声纹、本人对话更新、指定对象托付与人物模型 v0.12

状态：2026-10-15 Product / Integration Owner 在当前会话明确要求实施。该批准覆盖普通及多人录音、同一手机多人 Twin 对话、托付声音提示＋语音确认＋密语解锁、仅本人声纹匹配的对话记忆更新、独立人物模型图。旧提案的这些批准点以本次修订为准，不授权硬件或未核验自动身后激活。

- 按开始为本次 RECORDING / CLOUD_TWIN / VOICE / SPEAKER_IDENTIFICATION 分别生成服务器许可记录，无重复开关或固定同意句。首次本人声纹在已登录本人发起的“记住我的声音”普通对话中，从清晰单人自然介绍建立；后续相似度匹配不能靠自述姓名覆盖本人模板。声音合成档案与识别模板是不同资产。
- 使用后端 SpeakerEncoder 适配器提取真实声学向量，模板限 Subject，记录模型版本、来源及许可。未知、近似候选冲突、太短、重叠和服务不可用均不授予本人归属；仍保存录音、继续回答。姓名是自述标签，不是账号或密码。
- 普通录音可在原音声纹分析，已分清的他人证据不会进入本人模型，多人按 Paraformer 时间段各自匹配；多人原音不整体进本人模型。实时麦克风每轮单独上传后台分析，按分离段只取匹配本人原话；人工输入／旧未验证聊天仍可交流，但不绕过语音本人更新门槛。
- 本人匹配的原话自动成为可检索资料并通过现有抽取 worker 更新模型，保留机器原文及匹配证据。AI 回答、访客和无法确认的声音不自动成为本人经历。撤销许可或删模板使依赖的自动资料停用并重算。
- 托付以整段 Episode 为实际开放边界，绑定已登录指定 Actor、独立 DIGITAL_HANDOVER 许可、当前资源范围与密语哈希。声音候选／语音“我是”只辅助交互；账号＋计划＋密语必须都通过。解锁10分钟，连续5次失败暂停10分钟，密语不进入 LLM、聊天、日志或声纹样本。重置／撤权／来源变化使旧会话失效。身后条件不由声音、密码或 LLM 自动激活；需事先指定的 Steward 提交核验记录，由审核状态控制并冻结模型。访客不会更新历史本人模型。
- 人物模型按钮置于 Twin 右上角，人体填色和百分比表示“资料覆盖”，不是人格还原准确率。七领域各以5个不同有效来源为当前可视化目标，重复内容去重、只计有有效本人证据的 active trait；上限95%，删除／撤权／冲突会下降，展示来源计数、版本和计算方法。复刻验证保留独立真实测量。

依赖保持适配器和能力降级。模型下载来自 sherpa-onnx 官方模型发布；服务端计算，客户端不持向量、厂商密钥。首次登记基于本人已登录设备和声明，声音可能被模仿或播放，故不能作为密码或授权凭证。

本版数字交接是事先指定照护人的人工核验记录与争议暂停，并非自动判定死亡或独立机构认证。访客使用自己的独立用途许可；解锁句柄绑定当前设备登录。本人对话保留对应本人原音，模型在本轮播放结束后发布更新。
