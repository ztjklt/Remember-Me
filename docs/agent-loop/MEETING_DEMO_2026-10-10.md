## 本次发现并解决的阻塞

1. 测试音频注入依赖缺失，之后 Python 原生 gRPC 扩展被本机应用控制阻止。未修改系统安全策略；测试端改用官方 JavaScript gRPC 实现与模拟器公开接口通信。最终新录音有实际语音信号并由 ECS 成功识别。前两次无有效输入的尝试保留，不计为成功。
2. Android 提问后键盘没有自动收起，挡住结果。提交时清除焦点并收起键盘，实跑截图已确认改善。
3. **亲友已获云端问答授权却被 APP 拒绝**：ECS 的旧授权行返回数字 `1`，Android 的 `optBoolean` 将它读为 false。新增严格兼容读取，仅允许布尔 true 或数值 1；0、false、其他数字、未知字符串与缺失字段继续拒绝。服务器仍负责最终鉴权，没有放宽权限。先复现单元测试失败，修复后全部 52 项 Android 单元测试通过，亲友实跑问答与补问通过。
