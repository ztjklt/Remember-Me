# A01 人物档案与亲友补记实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Independent task work uses dispatching-parallel-agents; integration is sequential.

**Goal:** 用新十段讲述验证人物理解并交付本地可用的补记、留言和只读封存体验。
**Architecture:** 复用现有Episode/Memory/Evidence、权限、候选和模型提供者；附加贡献/留言/快照资源不形成第二套本人事实库。
**Tech Stack:** Python/FastAPI/SQLAlchemy/Alembic、现有AI Core、Kotlin/Compose。
**Spec:** A01_NIGHT_SPEC_2026-10-12.md

## Global Constraints

- 仅本地 codex/twin-a01-local-20261012；不push/merge/publish、不部署ECS、不更换供应商、不输出密钥。
- 文稿真值/答案不得进入模型；明确文本输入而非假ASR；保留不确定性和来源限制。
- 本人授权继续控制一切读取；仅确认的本人资料进入确定性画像。

## Review Focus

- 有贡献权没有阅读权的亲友：可提交但读不到本人旧资料。
- 接受亲友记录后：署名仍是亲友，不变成本人原话。
- 快照/留言的旧链接：撤权后拒绝读取，不因缓存绕过。
- 新批次有反例：不把前一批倾向提升为无条件稳定人格。
- 文稿元信息含精确日期：来源正文没说就不能作答。
