# 勿忘我：下载安装与两人体验说明

## 1. 下载并安装

[直接下载 Android 0.7.1 安装包](https://github.com/ztjklt/Remember-Me/releases/download/demo-android-0.7.1-20261010/remember-me-0.7.1-internal.apk) · [下载页与文件校验](https://github.com/ztjklt/Remember-Me/releases/tag/demo-android-0.7.1-20261010)

适用于 Android 8.0 及以上，约 149 MB。安装时允许该下载工具安装应用；进入 App 后按提示允许麦克风。已有同签名内测版可直接更新，不必卸载。**iPhone 不能安装这个 APK，iOS 本次尚未交付。**

服务地址已经配好。无需设置模型密钥、电脑转写、SSH 或固定 Wi-Fi；手机网络需能访问服务器。

## 3. 记录者：录音 → 核对 → 形成记忆

1. 登录记录者账号，进入“今天”。
2. 勾选录音同意，点击“开始录音”，讲一段 30–60 秒的虚构故事。可以暂停、继续。
3. 点击“停止并保留原音”，再点击“播放本机原音”，先确认确实录到了声音。
4. 勾选本段云端转写同意，点击“上传并等待核对”。等待后进入“档案”。
5. 点击这段录音的“核对转写”。修正名字、年份、错字，尤其检查“不是、不喜欢、可能”等限定。“本次补充说明（选填）”用于加入没说清的文字，不冒充录音原话。
6. 勾选文字确认与云端整理同意，点击“确认文字并整理”，等待完成。打开故事，查看记忆、核对文字和原音；“对话”可提问并打开来源。
7. 想看人物整理时，进入“档案 → 人物 → 整理故事 / 留下寄语”，选定材料、同意云端整理，点击“整理选定讲述”。完成后点“待核对 … 项”看建议及来源，只有认可时才确认。八个侧面、四个视图没有材料时为空，属于正常表现。

可以这样讲，全部使用虚构设定：

> 这是测试故事，我叫林川。2014 年我第一次上夜班，出门前妈妈送了我一个蓝色水杯。我一直留着它，因为看见杯子就会想起她。方宁是我的妹妹，她常提醒我下班后报个平安。我喜欢周末散步，但不喜欢攀岩。以后可能想去海边，还没有决定。

整理后试问：“蓝色水杯是谁送的？”“方宁和记录者是什么关系？”每次提问按界面同意使用有权材料参与云端问答，并点开引用来源核对。**流程可用不表示回答一定正确。**

## 4. 记录者和亲友：分享 → 聆听 → 提问

1. **记录者**进入“我的”，选择自己的测试录音，点击“预览分享范围”。核对整段原音和完整文字；勾选分享确认。需要亲友问答时，另勾选云端问答同意，再生成邀请码。
2. **亲友**在另一台设备登录亲友账号，进入“我的”，粘贴邀请码并领取。**领取后还不能读故事。** 没有第二台设备时，也可在同一台 App 中退出、换账号依次操作。
3. **记录者**返回“我的”，检查接收账号为 `remember_public_reader`，点击“确认账号并批准”。
4. **亲友**从顶部空间列表选择“公开演示记录者”的授权空间，找刚才的测试故事，播放完整原音，再到“对话”提问。若列表未更新，重新进入空间。
5. 对没有相关材料的问题，系统应说明目前不知道。亲友可在“我的”提交“请记录者补充讲述”的问题；记录者能收到并选择回答、稍后或拒绝。
6. **记录者**补录后仍要核对、整理，并重新预览分享新录音；原邀请不会自动开放新内容。最后可在“我的”撤销分享，亲友后续访问应受限。

公开账号只能演示两种身份的流程；由于密码公开，不能提供真正私密的两人关系或防止别人操作这些演示空间。

## 5. 有问题时怎么处理

- **连接或登录失败**：在登录页点击“检查连接”，确认网络、手机日期、账号与密码。注册仍关闭，不用尝试自助注册。连续失败先等一会再试。
- **处理慢或失败**：不要反复上传；查看当前是转写还是整理阶段，按该阶段重试。先前保存的原音仍可播放。
- **转写或理解不对**：先听原音并核对文字，再整理；人物候选不满意就不确认。短录音不一定形成丰富画像，不能以四视图为空判断整条链路失败。

后台实际流程是：**手机录音 → ECS 保存 → Paraformer 转写 → 本人核对 → DeepSeek 整理保存 → 记忆/人物候选/来源问答 → 本人授权 → 亲友使用。** 模型密钥只在服务器。
