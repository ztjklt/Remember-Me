# Android 0.10.0：下载安装与 Twin 体验

本页用于 **连接 ECS 的签名内测包**。CI 中名为 `local-twin-review` 的 APK 用于本地开发，不是给队友直接试用的包。

## 1. 下载、安装

- [下载 0.10.0 安装包](https://github.com/ztjklt/Remember-Me/releases/download/demo-android-0.10.0-20261013/remember-me-0.10.0-internal.apk)
- [版本说明、校验文件](https://github.com/ztjklt/Remember-Me/releases/tag/demo-android-0.10.0-20261013)
- Android 8.0 及以上。已有同签名的勿忘我内测版可以直接覆盖安装，保留本机录音；不需要先卸载。
- 打开后直接登录，不填写服务器、Actor ID 或模型密钥。不需要电脑、SSH、ADB 转发或固定 Wi-Fi。
- 默认服务地址是 `https://39.108.183.47`，App 保留证书验证。普通浏览器的证书提示不能通过关闭 App 的证书校验解决。

## 2. 用什么账号

| --- | --- | --- |
| 看陈守义十段故事，作为记录者体验 | `chensy08` | `story008` |

## 3. 先走一遍已有故事与分身

1. 用 `chensy08` 登录，选择“陈守义”空间。
2. 打开 **档案 → 花田**，点故事花朵，再点记忆花瓣，查看内容与原音。也可以用 **全部录音** 找到完整故事。
3. 打开 **人物**，在“了解这个人”中查看人生足迹、重要的人、在意选择、声音表达；“记忆侧面”展示八个内容入口。
4. 打开 **对话**。“查找记录”用于来源问答；“与 AI 分身聊聊”使用已确认且当前可见的人物理解与表达。记录者可开启或关闭“允许分身使用已确认的理解与表达”。
5. 输入“临近收车，考虑要不要再多跑一趟时，你会看重什么？”，确认本次云端模型使用，再点击 **提问**。
6. 查看新回答，通过 **查看理解与来源** 回到材料；点击 **听这条回答** 生成并播放分身声音。陈守义样例使用虚构音色，和播放原录音是两项功能。
7. 在 **我的 → 账号与空间** 退出，换 `chenly08`。亲友可以浏览获授权的同一片花田、查看人物内容、提问和聆听；没有本人的编辑权限。

如果上次开启了简明模式，可在“我的”切回完整模式找到上述入口。简明模式继续保留“讲一段、听故事、聊一聊”。

## 4. 再录一段并分享给亲友

1. 用 `flower08` 登录，在 **今天 → 讲一段** 录制约 20–30 秒连续讲述，完成后先试听。
2. 选择转文字并同意上传识别。服务器通过 Paraformer 转写；等待进入文字核对。
3. 修正名字、错字和时间；没有在录音里说出的内容放入书面补充。确认后同意整理，等待记忆生成。
4. 回到档案查看故事、记忆和原音。人物理解是候选，需要本人核对；不是每录一段都会自动产生一个稳定特点。
5. 在分享入口选择故事，预览完整录音及文字范围，创建邀请。
6. `friend08` 登录领取邀请码；`flower08` 核对接收账号并批准后，亲友才可访问。
7. 亲友提问，材料没有回答时可以提交补问；本人补录、核对整理，再明确分享新增内容。
8. 本人撤销分享后，亲友后续读取与播放受限。新录音、新补记不会自动纳入旧分享。

“亲友补记”还允许留下自己的文字或录音，由本人处理，并保留贡献者署名。声音授权、补记的模型使用授权与故事分享是独立操作。

## 5. 遇到这些状态怎么办

| 看到什么 | 下一步 |
| --- | --- |
| 已保存，转写失败 | 原音保留。先试听；有连续讲话再重试转写，不用重新录制或重复上传 |
| 待核对 | 打开核对稿，确认后才进入整理 |
| 整理失败 | 原音和文字保留，按失败阶段重试 |
| 目前记录不足 | 本次材料没有足够答案；换成已有故事相关问题，或补充新讲述 |
| 回答只答了一部分 | 看未回答部分和相关故事；部分回答不等于整题已经完整 |
| 声音生成失败 | 文字回答保留，仅重试声音，不必重新提问 |
| 亲友看不到故事 | 先确认进入同一人物空间，再检查本人是否已批准邀请并分享了这段录音 |
| 登录或连接失败 | 检查网络和版本；向维护者提供时间、页面和错误提示，不发送模型密钥 |
