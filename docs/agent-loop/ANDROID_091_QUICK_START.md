# 勿忘我 0.9.1：花径与人物阅读

[下载 Android 安装包](https://github.com/ztjklt/Remember-Me/releases/download/demo-android-0.9.1-20261011/remember-me-0.9.1-internal.apk) · [版本与校验文件](https://github.com/ztjklt/Remember-Me/releases/tag/demo-android-0.9.1-20261011)

Android 8.0 及以上，可覆盖安装旧内测版，保留本机录音。默认连接现有 ECS，不需要电脑转发或填写模型密钥。iPhone 不能安装此 APK。

## 先打开完整样例

| 用途 | 账号 | 密码 |
|---|---|---|
| 记录者 | `chensy08` | `story008` |
| 亲友 | `chenly08` | `listen08` |

登录后选择 **陈守义 · 虚构人物**。亲友账号还拥有自己的空空间；它不是陈守义留下的花田。新版本遇到多个空间会先让你选择，之后记住该账号上次的选择。右上角可随时切换，展开可见完整名称和当前角色。

两个账号均可进入 **档案 → 花田**。记录者有 10 段录音，亲友获授权 8 段，不会为了显示相同数量而开放私密内容。

## 五分钟体验

1. **花田**：沿藤蔓花径浏览；点击蓝花，再点一个记忆花瓣。缩放条与双指放大已移除。
2. **听原音**：阅读内容，展开依据，点“听完整原音”；返回花朵，再返回原来的花径位置。
3. **人物 → 了解这个人**：切换人生足迹、重要的人、在意选择、声音表达。左右滑动换一条内容，上下滑动只阅读当前卡片，视角入口保留在上方；也可点左右箭头。
4. **人物 → 记忆侧面**：八个侧面显示真实内容预览。点击一个侧面，再左右阅读相关记录。放大字号时顶部选项可横向滑动。
5. **查找与问答**：花田“查找”试搜“王建国”，返回可打开的材料；“对话”可问“第一次独立跑十二路是哪一年？”或“去西湖的计划定了吗？”。查询与生成回答是两个操作。

记录者的人物页右上角调节图标是 **整理与核对**，包含材料选择、待核对内容与寄语入口。阅读卡片仍可展开依据、查看历史、编辑或撤回，亲友没有这些管理权限。

## 自己录音与两人分享

建议使用练习账号：记录者 **`flower08` / `story008`**，亲友 **`friend08` / `listen08`**。不要修改完整样例来练习。

**今天 → 讲一段 → 开始录音 → 完成并保存 → 试听 → 同意上传识别 → 转成文字 → 修正文字 → 同意并确认整理。** 完成后进入花田；未形成记忆的原音仍在“全部录音”。

记录者在 **我的 → 亲友与分享** 预览完整录音范围并生成邀请；亲友领取后，记录者还需确认接收账号并批准。新补录需要另外分享，撤权后后续访问受限。

逐步录音、邀请、补问与撤权步骤沿用 [0.9.0 操作说明](ANDROID_090_QUICK_START.md)。其中“人物 → 整理与寄语”旧入口，已改为本版人物页的“整理与核对”图标。切换账号在 **我的 → 账号与空间 → 退出登录 / 换个账号**。

公开账号是多人共用的虚构素材测试账号。个人真实材料应使用独立内测账号。测试证书当前有效至 2027-01-07，需在到期前更新客户端信任配置及服务器证书。

## 本版的准确边界

本版更新 Android 显示、导航和空间选择，没有替换 ECS 程序、修改数据库迁移或重新运行音频生成／转写／全部问答评测。原有新版十段音频与整理结果继续使用。模型归纳并非全部自动正确；目前还发现人物候选过度失效的后台问题，详见 [Agent 实现与待改进项](AGENT_CAPABILITIES_2026-10-11.md)。
