## 先看完整的陈守义样例

| 身份 | 账号 | 密码 |
|---|---|---|
| 样例记录者 | `chensy08` | `story008` |
| 样例亲友 | `chenly08` | `listen08` |

选择 **陈守义 · 虚构人物** 空间。亲友登录后若进入自己的空空间，点顶部名称切换到获授权空间。

1. **档案 → 花田**：沿花径浏览，点花、点花瓣，读内容和依据，点“听完整原音”；返回时保留位置。
2. **人物 → 了解这个人**：切换人生足迹、重要的人、在意选择、声音表达，展开来源。
3. **人物 → 记忆侧面**：八个侧面先看预览，再进入实际内容。
4. **花田 → 列表 / 查找**：试搜“王建国”“旧杯子”；“查找相关内容”是检索，“问一问”才生成回答。
5. **对话**：试问“第一次独立跑十二路是哪一年？”“两位王建国分别是谁？”“去西湖的计划定了吗？”，同时查看引用。

记录者有10段新录音，亲友获授权8段。第07段是私密测试，第01段含已失效说法，保守规则不整段分享。虚构稿经真实小米TTS、Paraformer识别、独立技术核对和DeepSeek处理，部分故事经过人工技术修正；不表示全自动无误。音频合计约10分钟。

## 自己录一段

建议另用练习空间，避免改乱完整样例：记录者 **`flower08` / `story008`**，亲友 **`friend08` / `listen08`**。账号、密码均为8位，旧账号没有重置。

1. **今天 → 讲一段 → 开始录音**。首次允许麦克风，讲30–60秒虚构内容，可暂停、继续。
2. **完成并保存** 后进入录音库，先 **播放本机原音**。
3. 勾选这段完整原音的上传识别同意，点 **转成文字**。
4. **全部录音 → 核对转写**：修正名字、年份、错字和否定。“本次补充说明”用于原音没有说出的文字。
5. 同意核对文字与云端整理，点 **确认文字并整理**。完成后进入花田、阅读记忆或提问。
6. 组织多个故事和人物时，进 **人物 → 整理与寄语**，选择材料并确认；到“待核对”查看建议与来源后决定确认、修改或拒绝。

例子：

> 我叫林川，这是测试故事。2014年第一次上夜班前，妈妈送了我一个蓝色水杯。方宁是我的妹妹，她常提醒我下班报平安。我喜欢散步，但不喜欢攀岩。以后可能想去海边，还没决定。

## 两人分享、补充和撤权

1. 记录者进入 **我的 → 亲友与分享**，选录音并 **预览分享范围**；确认完整原音和文字，需要问答时另确认云端用途，然后生成邀请码。
2. 亲友登录自己的账号，在同页领取。领取并不立即开放故事。
3. 记录者核对接收账号与昵称，点 **确认账号并批准**。
4. 亲友选择获授权空间，浏览、听原音、提问。
5. 没有答案时，可在 **我的 → 待处理与核对** 提交问题；本人可回答、稍后或拒绝。
6. 新录音继续核对和整理，之后明确分享新材料；旧邀请不自动扩大授权。
7. 记录者可在分享页撤权，后续访问受限。已听到或另存的内容无法远程收回。

只有一台设备，可在 **我的 → 账号与空间 → 退出登录 / 换个账号** 轮流操作。

## 遇到问题

- 连接失败：登录页“检查连接”，确认网络、手机日期和账号；注册仍关闭。
- 转写失败：先试听；“未检测到有效语音”是识别没有找到讲话，不等于没上传。按当前阶段重试，不重复上传多份。
- 文字有误：核对后再整理。尚未“确认文字并整理”的录音不进入正式记忆。
- 回答不知道：检查已整理、已授权；材料确实不足时补录，不把未知一概算错。
- 外观与权限：我的 → 外观与阅读 / 设备权限与提醒。清下载缓存不会删除本机录音。

**公开账号为多人共用，只用虚构故事，不存真实私事。** 私人资料需要独立内测账号；模型密钥、管理员凭据不在APK或仓库。
