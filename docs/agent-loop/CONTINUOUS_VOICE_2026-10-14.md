## 批次

1. 实时 Paraformer 与小米预置流式 TTS：协议测试、ECS 实际小样。
2. 有认证、轮次、取消、播放进度及来源复核的语音会话；短回答、追问和逐轮检索。
3. Android 收音、播放、打断、生命周期；语音校准接线。
4. 内容与延迟分别验收；独立复核；受控 ECS 与同签名 APK。

## 实施决策

- Ruling: 会话为单 API 进程内的短期状态，重启即结束，不创建第二套事实库。限制连接时长、数量，重新连接必须新建会话。代价：当前版本不支持多 API worker 无粘性路由部署。
- Ruling: 先收到已审阅的完整短答，再串流 PCM；旧文字问答、文件录音和复刻音色路径保持兼容。代价：模型审阅延迟依然存在，不能提前承诺 1–2 秒。
