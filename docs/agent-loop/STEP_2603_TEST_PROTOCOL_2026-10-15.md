# Step 2603 low：接入与对比口径

本次只接入隔离的语音来源选择适配器，不修改 ECS 生产默认模型、数据库、权限或 APK。用 ECS 当前已发布的 `QuotedTwin`、提示词与原七题材料进行测试，不拿本地尚未发布的压缩提示词与服务器版本混比。正式结果另见同日 comparison 文档。

## 运行范围

- Step 标准中国区 API：`https://api.stepfun.com/v1/chat/completions`。
- 模型固定 `step-3.5-flash-2603`，`reasoning_effort=low`，SSE，JSON Object，输出上限 2048 token。该上限给思考留空间，不缩短或截断输入记忆。
- 微信保持实际线上 `Deepseek-v4-flash` 参数，包括供应商默认输出预算。两个模型使用相同问题、原文、已确认整理、来源选择结构与最终来源校验。供应商的 tokenizer 和输出预算并非相同；不能解释成纯粹硬件性能实验。
- 语义大模型审阅均关闭，与当前快速语音路径一致；精确来源、结构、版本/权限上游过滤继续保留。这是模拟已授权材料到文字回答的环节，不是新一轮权限安全验收。
- 第一组：七题各五轮，交替先后顺序，串行请求、间隔五秒。两边套用线上相同的 3 秒首尝试、最多一次重试、总计 8 秒策略。
- 诊断组：如果 Step 在持续输出思考时被 3 秒策略取消，另测不在 3 秒重启的同题请求。独立保存，不能替换第一组的失败。诊断组期限与轮数写入 manifest。
- 保存首次与后续请求，不剔除冷启动、超时或格式错误；429/鉴权失败即停止当前批次，不持续重试。

## 时间口径

记录连接、TLS、发送完成、响应头、首次思考、首次正文、首个完整来源选择点、完整来源校验结束。各事件时间从同一次尝试开始累计，重试另有起点；报告逻辑请求总等待。

**首次思考不是可以播报的答案。** 有效结果必须满足完成标记、JSON、来源 ID 与渲染校验。单纯 HTTP 200 或首 token 不算回答成功。本次不调用 TTS，不将这些数值冒称“讲完到手机出声”。

观察到探针存在 reasoning 文本但 usage 的 reasoning_tokens 为 0，故同时记录思考字符数与原始计量字段；不能根据后者认定没有思考。不保存或展示思考正文。

## 内容审阅

沿用此前回归关注点，按问题实际要求审阅，不要求字面一致，不强制每题复述全部资料。

| 问题 | 合格所需内容 | 需要指出的问题 |
|---|---|---|
| 公交工作的故事 | 一段真实、连贯的工作经历；涉及年份时采用已纠正的 1987 | 把“证件已找到”与旧的“仍未找到”并列却不交代先后；只给零散无关细节 |
| 喜欢什么茶 | 淡一些，不太甜；保留个人口味的归属 | 误写为医嘱、强制限制或具体茶品种 |
| 浓一点还是淡一点 | 淡；不改变上述条件 | 浓淡颠倒、凭空补原因。冻结样本历史为空，问题自身带“茶”，不算真实多轮指代通过 |
| 第一次独立跑十二路年份 | 1987，并不承认 1986 为当前正确年份 | 新旧年份倒置；编造具体月日 |
| 为什么旧记录写1986 | 相邻年份记混，后来找到工作证纠正 | 只说1987却没解释原因。此题明确问旧记录，按先后引用旧状态和纠正不能机械判错 |
| 银行卡密码 | 材料不足，UNKNOWN | 编造密码；把接口错误充作正确UNKNOWN |
| 旧杯子为什么留着 | 看见杯子联想到收车后站房喝水、一天忙完的感受 | 只重复“没有扔”，没有回答原因；误说女儿送的或造出事故 |

评分分开：

- 合格：回答主要问题，事实/归属/关键条件有依据。
- 部分：所说内容有依据，但关键原因漏掉或先后关系表达不清。
- 不合格：关键事实错误、无依据扩写、错误拒答等。
- 未返回：超时/结构失败/供应商错误，单独统计，不能当语义合格。

由本轮开发助手逐条对照原文复核、保存判据，不用关键词脚本决定语义分数，也不冒称独立人工盲评。保留争议原文。只报告这七题合成材料的效果，不能外推长期可靠率或人物相似度。

## 代码与运行

- `services/ai-core/app/providers/step.py`：仅供语音来源选择的候选适配器；普通记忆提取、人物归纳和非流式聊天尚未接到该适配器。
- `tools/voice_call/step_probe.py`：鉴权、模型列表和极短低推理流式协议探针。
- `tools/voice_call/benchmark_step.py`：从指定路径加载候选适配器，其余逻辑从当前发布版本读取。
- Key 只位于本机 Git 忽略的私有配置和 ECS 独立目录中，ECS 文件权限 600；报告只引用路径，不包含 Key。
- 再跑时使用新的输出目录，脚本拒绝覆盖已有结果。`--providers step --retry-after 0 --deadline 12` 可运行单独诊断；默认同时比较两边，8 秒总期限。

官方参数来源：[Step 3.5](https://platform.stepfun.com/docs/zh/guides/models/step-3.5-flash)、[Chat Completions](https://platform.stepfun.com/docs/zh/api-reference/chat/chat-completion-create)。模型列表只说明列出了这些 ID，不等于每个接口均已调用验收。
