# 勿忘我 0.9.3：简明模式试用

[下载安装包](https://github.com/ztjklt/Remember-Me/releases/download/demo-android-0.9.3-20261011/remember-me-0.9.3-internal.apk) · [版本与校验文件](https://github.com/ztjklt/Remember-Me/releases/tag/demo-android-0.9.3-20261011)

Android 8.0 及以上，可直接覆盖旧内测包。使用原有 ECS，无需电脑转写或填写模型密钥。这次增加的是 Android 简明模式，未更换后端或模型。

## 怎么开启

登录后进入 **我的 → 简明模式**，点击开启；再次点击即可恢复完整模式。选择保存在当前手机上，重启后保留，不会改变账号角色或故事授权。

正文基础字号约 20sp，继续跟随系统字体设置；主要操作使用较大的按钮和稳定底色。简明模式中的花田自动减少过渡动画，完整模式的个人动效偏好保留。

## 两种身份怎么用

| 用途 | 账号 | 密码 |
|---|---|---|
| 完整虚构样例：记录者 | `chensy08` | `story008` |
| 完整虚构样例：亲友 | `chenly08` | `listen08` |
| 自己练习：记录者 | `flower08` | `story008` |
| 自己练习：亲友 | `friend08` | `listen08` |

完整样例选择“陈守义 · 虚构人物”。这些公开账号由多人共用，仅用于虚构材料；练习与展示空间分开。

**记录者留下声音**

1. 今天 → **讲一段故事** → 开始录音。
2. 随时暂停或继续，结束时点 **完成并保存**。原音先留在本机。
3. 在“我的录音”试听；愿意转写时，确认上传原音，再点 **转成文字**。
4. 检查完整识别文字，修正名字或错字；新增说明另写在补充框。
5. 确认云端整理后提交。也可以先返回，之后从 **继续整理** 接着处理。未提交的文字修改不会自动保存，退出前会提醒。

**自己或亲友听故事**

1. 今天 → **听我的故事 / 听故事**。页面只列当前可见、已核对并完成整理的讲述。
2. 每条都有 **听这段原音**，不必先点花瓣；**播放控制** 中可以暂停、继续、从头再听或停止。
3. **读故事与记忆** 查看文字和来源；**去花田看看** 仍可浏览花朵与花瓣；**了解这个人** 保留四视角及八个记忆侧面。
4. “按标题找故事”是本机标题匹配；更完整的查找仍在花田。“问答”沿用原有有来源问答流程。

分享继续在 **我的 → 亲友与分享** 中操作，领取邀请后仍需记录者批准。简明模式不会自动开放新故事。完整分享、补问和撤权步骤见 [双角色操作说明](ANDROID_090_QUICK_START.md)。

## 这一版的范围

这是简明模式的第一版，优先改善首页、录音、听故事、阅读和返回入口。人物审核、复杂分享和完整录音管理仍沿用既有流程，没有全部重新设计。

本轮模拟器验收与真人长辈试用分开记录；没有把模拟器录音当成真人 ASR 准确性验证，也没有声称已经完成所有适老化或认知障碍辅助能力。
