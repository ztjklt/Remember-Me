# 简明模式首轮试用

## 已批准的范围

在同一个 Android App 中增加可随时切换、在本机记住的简明模式。记录者优先看到“讲一段故事、听我的故事、继续整理”；亲友优先看到“听故事、问一问”。花田、人物、分享和完整模式继续可达。复用现有 ECS、身份、来源播放、文字核对及授权流程，不新增后端或自动确认。

文字采用较大的基础字号并继续响应系统字体；阅读使用稳定底色，主要按钮至少 60dp。原音提供明确的播放、暂停、重听，不要求精确拖动进度。录音保存后可以稍后再整理；完整核对稿、书面补充和云端确认保持原有语义。

## 实施与验证

1. 增加本机模式偏好、简明首页、故事直达播放与可返回的导航。
2. 扩大主要操作、固定弹窗返回入口，保持录音、核对、分享原有流程。
3. 使用两个普通账号连接真实 ECS，验证模式重启保持、角色差异、录音暂停与保存、来源播放、延后整理、花田及完整模式切换；分别检查正常字号和 200% 字号。
4. Android 单元测试、完整模式回归、独立代码审阅。交付可安装 APK、实跑截图和已知限制。

## 本轮边界

这是一版可操作的简明模式试用，不能以模拟器证明适合所有老年人。真人长辈试用、认知障碍辅助流程、核对文字的机器朗读、家属协作核对均另行验证。本轮不增加新模型，不修改 ECS 数据或自动分享内容。

## 本轮发现并修复的问题

1. **录音保存按钮越过屏幕底部**：旧浮动窗口在 Android 15 上的起点与高度不一致，语义点击通过也不能证明按钮可见。录音改为完整页面，并增加屏幕坐标与导航安全区域检查，正常字号和 200% 字号均通过。
2. **系统返回键退出应用**：简明模式从花田或人物返回时，现在回到故事列表；再返回首页，不直接退出。
3. **减少动效覆盖完整模式偏好**：简明模式仅使用临时生效的减少动效值，切换花园场景不会改写完整模式的个人设置。
4. **未提交文字误丢失**：显式关闭核对页时，有未提交文字修改会提示确认。尚未实现进程被系统终止后的编辑草稿恢复，不能视为自动保存。

独立审阅发现的前三项均已修复并复跑。测试历史保留：首次缺少模式入口、录音底部裁切、返回路径与动效偏好失败，均未记作通过。另一次 200% 记录者测试在播放等待处超时，当时没有足够状态证明原因；之后测试先等待按钮可用、超时输出播放器状态，重跑通过，没有据此修改播放权限或放宽验收。
