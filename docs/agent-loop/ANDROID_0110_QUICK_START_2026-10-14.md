## 连续聊一次

1. 登录，选择“陈守义”空间，打开 **对话**。
2. 选择“查找记录”或“与 AI 分身聊聊”。前者主要找本人说过的话；后者使用本人已确认且当前可见的人物理解，须先由记录者开启既有表达许可。
3. 点击 **语音聊聊 → 开始**，确认云端识别、回答及声音合成，允许麦克风。
4. 等“我在听”后说话，例如：“第一次独立跑十二路是哪一年？”无需每句点击提交。
5. 回答期间可继续开口；旧轮次停止，改为处理新问题。连续追问可试“为什么之前有一条记录说1986年？”
6. 展开 **字幕** 看当前问答，展开 **相关故事** 看本轮依据。查完整故事和原声仍可回到档案。
7. **静音**停止收音；**暂停**停止收音与播放，点**继续**恢复；**结束**关闭通话。切后台、音频设备变化或音频焦点被占用时会暂停，回到页面需手动继续。

普通音色使用“白桦”。这是新回答合成，不是故事原音，也不是本轮新增的真人声音克隆。

## 语音校准

1. 记录者在对话页输入一个问题，选择 **先录下我的回答，再对照**。
2. 后台先生成并锁定 Twin 答案，当前不展示也不播放它。
3. 选择 **录下我的想法** 或导入音频，完成上传、文字核对及整理。
4. 选择 **看看有哪些不同**，查看两边答案和比较；需要时点击 **听听这次对照**。
5. 比较仅作核对参考，不会自动改写人物理解。缺少情绪或取舍材料时，应保留无法比较；不同用词不等于答错。

## 目前应如何预期

- 已实测连续问答、跟随问题、流式播放、旧轮取消，以及模拟器公网连接。**仍是试验版**：生成与审阅通常需要数秒，不能期待每次1—2秒接话。
- “本轮未完成”是调用或校验失败；“现有记录不足”是没有足够依据。两者不同。不要反复连续提交相同问题。
- “你喜欢喝什么茶”这样的宽问题仍有审阅不稳定记录；可以明确问“平时喜欢浓茶还是淡茶”。这不是已经修复了原题。
- 通话不自动成为记忆。要留下新经历，请用 **今天 → 讲一段 → 核对 → 整理**；亲友使用署名补记。
- 实体手机的回声、耳机、来电、慢速停顿尚未验收；首轮试用建议安静环境、耳机，并主动检查是否误抢话。
- 旧有花田、人物、文件转写和分享入口保留。[逐项结果与失败记录](CONTINUOUS_VOICE_RESULTS_2026-10-14.md)。
