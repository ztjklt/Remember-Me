# 手机产品与 Agent 核心：现状、差距及下一步

2026-10-08。本轮在 `codex/agent-integration` 本地工作；不部署、不发布、不合并团队分支。

## 用户要的交付，与当前入口的区别

目标是安装手机 App 后，正常登录或接受邀请，便可录音、核对、整理、查看人物理解、提问和管理分享。用户不用输入服务器地址、Actor token、模型密钥或运行命令。

目前并非这个状态。网页是本机集成工作台，Android 的 `MainActivity` 也直接挂载 `NativeWorkbenchScreen`。其服务地址、身份凭据、空间选择是开发验证入口；真正防止读者看到私密资料的是服务端所有者与故事授权检查，不能为了省掉登录而删除这些检查。

UI PR #85 的自然背景、配色和品牌已经引用，但“今天／档案／对话／我的”的正式页面尚未完整接到真实服务。当前 Android 的“记述／故事／提问／管理”是另外一套功能验证布局。因此不能声称移动产品 UI 已完整融合。iOS 有配对、原有记忆/人物模型/校准接口，但尚未接齐本轮 workbench 的故事授权、人物候选、跨录音修订和读者问题单。

Android 调试 APK 已经安装并验证过登录与原音播放；设备通过 ADB 转发使用本机 8877。把这个 APK 拷到另一部未连接该后端的手机，不能因此获得完整服务。iOS 当前新增功能没有本轮编译或设备验收。

## 实际 Agent 结构

实际链路由共享后端协调，不是四个模型互相对话，也尚不是模型动态调用任意工具的通用自主代理：

```text
Android / iOS / 网页
  → 身份与故事授权 → 原音保存 → 云端 ASR → 等待核对
  → 整理任务 → 有证据的记忆
  → 人物候选任务 → 本人审核 → 当前有效人物理解
  → 可见原文 + 有效记忆 + 已确认理解 → Twin → 来源/权限版本复核
  → UNKNOWN 时提交问题单 → 本人补录 → 核对整理 → 主动分享
  → 先锁定 Twin 回答 → 收集本人回答 → 校准报告 → 人工决定修订
```

具体模块是录音处理 Worker、人物归纳 Worker、受限材料组装、一次在线 Twin 调用、校准比较和问题单。职责是合理的，不能用 Agent 数量证明功能完整。

## 本轮改进与验证边界

- Twin `twin-compact-v4/v5`：在权限过滤后的全部材料中按问题的字面相关性排序，不删除、不截断材料，不改变来源 ID、时间注释和反例；排序不能充当真实性分数。姓名只做精确字形匹配，不建立同音人名别名。当前运行v5，另强调主语核对与未知因果约束。
- 模型遇到姓名字形差异时，按材料原写法说明已知部分并明确待核对，不凭空合并人物，不把有依据的全部信息一起拒答。
- 独立真实 60 问新批次和独立 Groq 校准空间；旧批次结果不覆盖。任何失败都保留，不用替身成功代替真实调用。
- 本轮没有改共享接口、权限、引文校验或数据库迁移。新排序为 AI Core 内部协议变化，客户端继续接收原有三个回答类型。
- 本轮结果见 `AGENT_CORE_RESULTS_2026-10-08.md`；早期批次见 `GROQ_LIVE_RESULTS_2026-10-08.md`。v4全60问和v5定向15次分别记录，不能混算通过率。

## 下一步的交付顺序

1. **先完成 Agent 的可核验质量闭环。** 保留固定问答集；对漏答、摘要不受引用支持、转述归属、专名问题分别登记。将人物观察、候选与已确认理解在界面明确区分。语义纠错不通过悄悄改原始 ASR 实现。
2. **补智能建议，保留本人决定权。** 从明确证据提出补充/支持/冲突/变化建议，展示目标和理由；对重复故事不增加独立支持计数；同名人物不自动合并。读者归纳只使用获授权材料，来源变化即失效。先在固定材料上验证，再接常用入口。
3. **把已验证能力接回正式 Android 页面。** 今天/档案/对话/我的；录音、核对、来源播放、人物候选、修订、邀请授权、待答问题都有真实状态。开发凭据输入移到调试入口；普通用户使用登录/配对与邀请。首先模拟器完整跑一遍，再在实体手机验证。
4. **最后交付手机服务环境。** App 包含原生界面、录音/播放、离线草稿和会话管理；受管理的后端包含 API、处理任务、数据库、原音存储和模型适配，提供一个 HTTPS 服务地址。Groq/微信密钥只在后端。不是把第三方云服务或共享服务商密钥塞进 APK。
5. **iOS 接同一套规则后独立验收。** 在可用 Mac 上构建并运行模拟器，再走合适的签名与测试安装渠道。Android 通过不等于 iOS 通过。

本地一键启动 + 设备配对可以降低演示门槛，但仍依赖电脑在线。用户要求的“换一台手机、换网络也能使用”需要实际运行的远程后端和正式账户流程；本轮未授权公网发布，故不擅自部署。上述 Agent 与本地客户端工作可继续完成，不以部署未定为理由停下。

## 正式手机交付验收线

首次安装到“完成一段录音并看到记忆”不出现服务地址、token、命令行或模型密钥；重启保留会话；离线原音不丢；恢复网络可重试；双身份分别登录；邀请/撤权生效；纠正旧事实后问答同步变化；不知道就说明不知道；从回答能找到正确原音；拒绝麦克风权限后可重新授权。模拟器、实体 Android、iOS 三种验证分别记录，不能互相代替。
