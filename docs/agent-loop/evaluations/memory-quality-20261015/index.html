    这次如何判定

    合理改写不因用词不同判错；明确说过的经历、人物归属、否定、条件和不确定性必须保留。无依据的确定动机或责任判断属于错误；正确地说“不确定”可以通过。超时或结构失败单独记为失败，不算正确拒答。
