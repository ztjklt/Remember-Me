## Agent 质量不是接口成功率

v5、v6 各60问虽均返回58个答案，仍出现否定与人物归属错误，均未验收。v8完整60问为46个响应、14个失败。v9完整60问为40个响应、20个失败，已定位4条关键含义风险，其他响应不自动算通过。逐项复核另存 `var/round-two/qa-quotes-v9.json` 与审阅工作表；不得将接口失败算作合格 UNKNOWN。

需要分开的两个原因：

- `effective_materials` 曾把已提取的跨度从剩余句子中扣除。确定性探针确实重现“我没有说搬家能解决所有困难。”变成“我没有说”和“搬家能解决所有困难。”。这是代码缺陷，已修复。
- 对v9的实际失误继续追溯发现，其使用的旧 Whisper 机器稿本身也已丢失否定词。公交05和消防02尤其明显，不能把这几条实际失误全部归因于上述切分缺陷。模型不应擅自补写录音没有被可靠转出的内容；仅修改问答提示不能恢复缺失材料。

回归脚本此前固定读取 `var/monthly-eval/identities.json` 与 `product-episodes.json`，实际指向10月7日旧 Whisper 空间。10月8日云端转写的完整30段是另三个独立空间，位于 `cloud-asr-runs/relay-compact`。本轮逐段核对，**30/30音频哈希相同**，新空间转写来源为24段 codestral-2508、6段 Groq whisper-large-v3；没有新调用ASR，也没有使用创作原稿替代转写。当前授权、私密故事和纠正状态均与原60问协议相符。失败任务保留，但不进入有效材料。

现在把旧语料压力回归和后续完整云转写语料回归分开命名、分别记录，使用同一冻结问答实现与相同60问。不得挑选某些新转写替换旧结果，更不能把这套历史云转写结果称作Paraformer或真人验证。未授权材料仍不进入读者输入。

已完成对应代码修复：

1. 部分提取不再切断完整句子，保留完整的有效句子作为原文来源。
2. 含已删除/失效片段的句子不为补上下文而重新引入；第三方转述不能升级成本人经历。
3. 事实问答只选择同录音、同来源类型、同时间语义的完整包含跨度；被完整有效来源包含的残片不能再被单独选择。没有重新读取未授权的相邻原文。
4. 引文、权限、来源变更、JSON与语义审核仍保留；失败不降级为伪造的 UNKNOWN。

新增回归先重现失败再修复。最新本地后端全量 **447通过、3跳过**；AI Core **254通过**；新增完整句子逻辑在独立 PostgreSQL 环境的 **48项相关检查通过**。这些确定性测试证明修复规则，不证明真实模型达到54/60。新协议仍未启用于 ECS。

### v10 完整结果与有界恢复

同一冻结实现下，较新的完整云转写语料60问逐项审阅：55个响应，**53题合格、7题失败、关键错误0**，未达到54题门槛。两题人物指代不完整、三题结构/审阅失败、两题45秒传输超时；失败不计为UNKNOWN。审阅为助手依据材料的技术阅读，不是人工听读、真实本人认可或独立留出集。

评分保留用户先前允许的非致命ASR同音字形瑕疵，但不容许据此合并同名人物、反转否定、编造关系或时间。灰伞/灰散、梁舒/梁叔等问题另列；未把未确认别名写回事实。回答较长的阅读问题也未视为已解决。

v11只增加暂时性传输错误的有界恢复，选择与审阅提示保持v10不变：同一请求最多重试一次，所有选择、修复、审阅和传输重试共用最多3次模型请求预算，并为审阅预留调用；65秒后不再发起调用，单次仍45秒。鉴权、JSON、截断和语义失败不作为传输错误重试。原失败日志保留。不以补跑失败题覆盖v10，而重新记录完整60问。
