## Agent 质量不是接口成功率

v5、v6 各60问虽均返回58个答案，仍出现否定与人物归属错误，均未验收。v8完整60问为46个响应、14个失败。v9完整批次结果和逐项复核另存 `var/round-two/qa-quotes-v9.json` 与审阅工作表；不得将接口失败算作合格 UNKNOWN。

新的具体根因：`effective_materials` 曾把已提取的跨度从剩余句子中扣除。例如“我没有说搬家能解决所有困难。”可能拆成“我没有说”和“搬家能解决所有困难。”。这些碎片逐字存在，却不能独立表达原意。v9 中已发现引用这种残句的回答，因此即使其他题合格，也不能达到“零关键事实颠倒”的门槛。

已完成对应代码修复：

1. 部分提取不再切断完整句子，保留完整的有效句子作为原文来源。
2. 含已删除/失效片段的句子不为补上下文而重新引入；第三方转述不能升级成本人经历。
3. 事实问答只选择同录音、同来源类型、同时间语义的完整包含跨度；被完整有效来源包含的残片不能再被单独选择。没有重新读取未授权的相邻原文。
4. 引文、权限、来源变更、JSON与语义审核仍保留；失败不降级为伪造的 UNKNOWN。

新增回归先重现失败再修复。最新本地后端全量 **447通过、3跳过**；AI Core **254通过**。这些确定性测试证明修复规则，不证明真实模型达到54/60。新协议仍未启用于 ECS。
