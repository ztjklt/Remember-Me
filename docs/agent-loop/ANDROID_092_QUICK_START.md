# 勿忘我 0.9.2：人物理解与页面恢复修正

[下载 Android 安装包](https://github.com/ztjklt/Remember-Me/releases/download/demo-android-0.9.2-20261011/remember-me-0.9.2-internal.apk) · [版本及校验文件](https://github.com/ztjklt/Remember-Me/releases/tag/demo-android-0.9.2-20261011)

Android 8.0 及以上，使用与旧内测包相同的签名，可以覆盖安装并保留本机录音。默认直连现有 ECS，不需要电脑接力或填写模型密钥。iPhone 不能安装此 APK。

## 用这两个账号看完整样例

| 身份 | 账号 | 密码 |
|---|---|---|
| 记录者 | `chensy08` | `story008` |
| 亲友 | `chenly08` | `listen08` |

登录后选择 **陈守义 · 虚构人物**。亲友账号另有自己的空空间；可在右上角切换。记录者可见 10 段录音，亲友可见获授权的 8 段，两个身份均能进入 **档案 → 花田**。

1. 点一朵故事花，再点花瓣，查看内容并听完整原音；返回后仍在原来的花径位置。
2. 进入 **人物 → 了解这个人**。四视角保留在上方，左右滑动或点箭头换一条内容，上下滑动阅读当前卡片。
3. 记录者在 **在意选择** 中可看到两条新复核的理解，包括“喝茶喜欢淡一点”；展开 **支持、例外与依据**，查看原话和适用情境。这些是虚构素材的技术复核，不是真人认可。
4. **记忆侧面** 可按八个侧面浏览；花田“查找”试搜“王建国”。
5. **对话** 可问“他喝茶有什么口味偏好？”。本轮真实调用返回了有依据的原话；材料不足的问题仍可能不知道。

亲友可浏览共享故事、人物记录、情境观察及原音，但不会得到记录者的完整私人候选库。因此双方人物页的条目数量可以不同。

## 自己录一段

练习账号：记录者 **`flower08` / `story008`**；亲友 **`friend08` / `listen08`**。完整样例与练习空间分开，避免多人改坏展示素材。

**今天 → 讲一段 → 开始录音 → 完成并保存 → 试听 → 同意上传识别 → 转成文字 → 修正文字 → 确认云端整理 → 档案查看。**

邀请在 **我的 → 亲友与分享**：选择录音并预览，生成邀请；亲友领取后，本人核对接收账号再批准。新补录需要另行分享。详细录音、补问、分享和撤权步骤见 [0.9.0 操作说明](ANDROID_090_QUICK_START.md)，人物管理入口为当前人物页右上角的 **整理与核对** 图标。切换账号在 **我的 → 账号与空间**。

## 这次改好了什么

- ECS 已修复“新增问答同意后，原来核对过的人物理解突然失效”。真正修改材料、删除来源以及调用期间撤权仍会阻止旧结果生效。
- Android 15 重建页面后出现上下白边的问题已修正。花田、花瓣、右上角空间选择和横向人物阅读继续保留。
- 没有重新生成十段音频或重新验收全部问答；模型仍可能漏答或过度概括。
