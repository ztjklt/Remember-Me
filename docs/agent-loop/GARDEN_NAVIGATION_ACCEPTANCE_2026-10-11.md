| 改动 | 验证结果 |

## 本轮失败与修正

- 第一次编译发现复用的 `NativeDialog` 仍为私有，调整为同模块可见后重新构建通过。
- 首次 UI 测试遇到恢复登录后的强制选空间弹窗，测试无法切换账号；增加“退出账号”，并补上弹窗列表滚动。
- 分页测试原来以正文 tag 查找单个节点，但 Pager 会同时组合邻页，导致匹配两个节点。触控改为实际可见 Pager 区域，同时断言页码与固定导航；没有删除翻页验证。
- 审阅发现没有可访问空间时可能保留“必须选择”的标志，补上零／单／多空间状态测试，避免空弹窗困住用户。
- 大字号下顶部选项曾断成两行，改为横向可滚动的一行，不缩小系统字号；搜索按钮可滚动到达。

以上失败过程保留在本地验收目录；本页和 release JSON 报告最终同一个 APK 的结果，没有用旧包通过记录替代。

## 仍未解决或未验证

1. **人物候选过度失效**：历史上确认的两项候选当前均为 stale。当前有效确认数为 0；共 5 项 stale、1 项 rejected。新建问答授权也会改变其材料依据哈希，需要分开材料版本与权限版本后回归验证。本版没有修后台规则。已审核的故事、人物记录和情境观察仍可展示，不能把它们等同于有效人物候选。详见 [Agent 状态分析](AGENT_CAPABILITIES_2026-10-11.md)。
2. **系统栏重建外观**：instrumentation 的 Activity／模型重建截图中，上下系统栏出现浅色区域，花田状态栏图标对比不足；正常从桌面冷启动的花田没有出现同样白边。已保留原截图，未用修图掩盖；生命周期外观与真机仍需进一步复查，不能声称所有恢复外观已完善。
3. 新版实体 Android、完整 TalkBack 与 iOS 原生实现／编译尚未完成。200% 字号是可操作布局检查，不代表全部无障碍验收。
4. 情境理解、跨故事推理与自然表达仍有语义误差；UI 场景通过不代表模型质量合格。亲友专属材料的独立人物归纳尚未实现。

当前两端都可看到各自有权使用的花田。记录者 10 段、亲友 8 段是授权结果，不是为了视觉统一应当抹平的差异。账号和空间分别管理：同一个账号可以在自己的空间是 owner，在别人分享的空间是 reader。
