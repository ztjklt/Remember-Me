## 审查修复与测试位置

`services/backend/tests/test_agent_workbench.py` 包含：

- 自授权拒绝、整故事授权/撤权、私人人物归纳不进入读者模型输入；
- 生成中纠正；独立请求中的删除/撤权各重复三轮；检索编码期间撤权；
- IMPORT 等待核对、修订确认幂等、旧捕获者不能绕过新所有者；
- 已处理的旧录音不能被改成未确认修订；已确认时间变化不误判为矛盾；
- 问题单只能由本人处理，关联回答不自动新增授权。

历史部分测试原本断言“任意 Actor 可给同一 Subject 自授权”，已改为新所有者规则。
Windows 不具备 POSIX mode bits 语义，仅跳过 POSIX 位断言，保留文件读写测试；
没有把这个变化称作 Windows ACL 安全验收。
