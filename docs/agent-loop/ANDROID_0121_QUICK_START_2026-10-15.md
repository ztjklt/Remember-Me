## 先体验自动纠错

1. 用记录者账号登录，**今天 → 讲一段**，允许麦克风。讲完点完成并试听。
2. 选择转文字，在此步同意云端识别及文字校对。等到“继续整理”或录音库中的核对入口出现。
3. 打开 **看看这段文字 → 查看修改**。系统会主动提出并应用能确定的词语修订，拿不准的留下提示。可点 **恢复机器稿**、**恢复自动修订稿**，也能听原音、改文字。
4. 确认后点 **确认文字并整理**。这时才提取记忆。整理完成后从 **档案 → 全部录音** 查看内容、依据和原音。

本次真实识别样例把“没想多少轻浮”修为“没享多少清福”，把“蓝色搪瓷被”修为“蓝色搪瓷杯”；“该谢就谢／该歇就歇”保留为疑点，由这次测试人工核对。没有改动的录音也正常，不必故意制造错误。自动校对不重写旧录音，不等于核对全部人物理解。

原音先留在本机；上传、模型处理失败时从 **我的录音／全部录音** 找到该条，按页面提示重试对应阶段，不必重新录一份。高峰时整理或人物归纳可能需要等待；本轮仍有模型忙碌和审阅失败记录。

## 纠正一条已经形成的记忆

1. **档案 → 全部录音**，打开旧故事及其记忆。
2. 点该条的 **用新录音补充、纠正或说明变化**，选择“纠正”；如果是后来改变，选择变化并说明大致时间。
3. 录下新说明，转文字、核对并整理。进入 **我的 → 待处理与核对 → 核对修订关系**，点 **确认这次关系**。
4. 再到对话页提问，检查新回答和依据。旧原音保留，旧答案可能提示来源已变化。

已有杯子样例的新说明是“现在留作纪念，不是每天喝茶用的杯子”。亲友 `review16` 已能听到获分享的新录音，并可在 **查找记录** 问：“蓝色搪瓷杯现在是每天喝茶用的吗？”

**补录不会自动分享。** 新录音需要重新预览、授权。旧原音含被纠正内容时，整段旧录音可能不再允许重新分享；请分享完整的新说明，而不是继续把旧版本交给亲友。原音没有被修改或删除。

## 记录者分享，亲友接收

1. 记录者从 **我的 → 亲友与分享** 选择录音，预览将开放的完整原音和文字，并选择是否允许云端问答。
2. 生成邀请，把邀请码交给亲友。亲友登录自己的账号，在相同入口领取。
3. 记录者核对接收账号与昵称，点 **确认账号并批准**，亲友才可以读取。
4. 记录者可再次向已确认的接收人分享，但新增录音仍须预览与批准。撤销后，后续页面、原音和新回答受限制。

人物理解的全部支持和例外都可见时，亲友才会看到它。记录者有两项理解、亲友只有一项，不一定是 UI 丢失；先检查相关录音是否分享。本次只补分享了已核对的虚构“淡茶口味”补录；涉及失效旧录音的理解仍隐藏。

## 分身和连续语音

用 `chensy08` 或 `chenly08`，进入 **对话**：

- **查找记录**：查他说过什么，可打开依据听原音。
- **与 AI 分身聊聊**：根据已确认的理解作有条件的表达。记录者须先开启“允许分身使用已确认的理解与表达”。可以问：“如果我想喝浓一点的茶，你会怎么想？”
- **听这条回答**：把这次新答案合成声音；不是播放原始录音。

连续语音：**语音聊聊 → 选择路线 → 开始**，同意云端处理，等“我在听”再说话。默认保留审阅；试提速可打开 **快速回复**，或选 **实时试用**。每句不用按提交，回答时可以插话；字幕和相关故事可以展开。

可依次问“请讲讲公交工作中的故事”“停，不说工作了，你喜欢什么茶”“刚才说的茶浓一点还是淡一点”。**静音、暂停、结束**均在通话页；切后台后需手动继续。通话不会自动存为人物记忆，新经历仍用“讲一段”。

目前是连续语音试验版：本轮原路线三轮约 **7.45／2.65／6.41 秒**后听到声音，Step 复测约 **5.16／3.90／3.99 秒**；不是稳定两秒。首次亲友人物模拟发生过审阅拒绝，页面会提示失败，不等于“没有记忆”。不保证每次回答都成功或正确。实体手机的回声、耳机与慢速停顿尚未完成本轮验收。

## 找不到入口或无法连接

- 没有新纠错界面：先核对 0.12.1，并使用新上传的录音；旧记录不会自动重新校对。
- 看不到花田：核对当前人物空间和分享状态；尚未整理的录音先去“全部录音”找。
- 不能进入连续语音：本轮只有两个陈守义账号在名单内，其他普通功能不受影响。
- 连接失败：检查网络和设备日期；不需要配置 Key。不要关闭证书验证或改用 HTTP。当前内测证书到 **2027-01-07 02:56:56 UTC**，到期前需要维护者更新服务器证书及同签名安装包。
- 遇到失败，提供 App 版本、账号、操作时间和界面提示，便于对应任务日志；不要把真实个人资料写进公开 Issue。
