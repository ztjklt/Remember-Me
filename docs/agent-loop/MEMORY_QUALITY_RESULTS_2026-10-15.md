# 记忆质量第一批修复：提取边界与修订传播

本轮已修改本地实现，并做真实模型对照和隔离数据库实跑。没有部署 ECS、更新 APK 或推送 GitHub。现有语音改动保留。

## 已落实的变化

1. **一个理解可引用多个语义片段。** 微信提取协议由 v4 升为 v5，保存主体、时间、条件、否定、不确定性和转述的原文短语。选中的片段之间若还有限定句，一并保留。使用所选位置而非第一次字符串匹配，避免重复原句定位错误。严格检查原文位置和引用；语义是否成立仍需核对。
2. **修一处，不再默认丢掉整段里的其他事实。** 修订记录保留首次原始来源 ID；连续修改、再删除均能定位原句。书面补充的修订不再屏蔽原音。原音、机器稿、旧依据和审计历史保留。
3. **共用失效依据的摘要退出当前使用。** 检索、基础人物整理、当前记忆列表、有修订的处理结果和校准检查共用有效来源判断。记录者故事页把受影响条目标为待核对，保留处理入口。已失效校准隐藏旧答案，不继续比较。
4. **权限和回答失效机制保留。** 修订、删除进入已有发布锁；旧问答/派生语音继续失效。亲友不能修改本人的记忆；历史版本不能借修订接口重新激活。新增修订仍须重新分享。

这些是兼容现有 API 和 metadata 的修改，没有增加数据库迁移。七领域基础投影仍不是“已确认人格”；条件化 ProfileCandidate 继续单独审核。

## 陈国梁实际样例：六处修订

使用历史本地 A01 SQLite 的在线备份创建隔离副本。测试绑定已知记录者身份，再调用现有 PATCH 接口；没有直接 UPDATE 原始记忆库。此步骤不算真实登录验收，账号隔离另有回归测试。

| 原记忆中的问题 | 隔离副本中的修订 |
|---|---|
| 不是“电击”坏 | 不是电机坏，是小螺丝松了 |
| 太“认私理” | 有时太认死理、不爱听劝；现在认为不一定都对 |
| 误怪桂芳 | 曾指责桂芳，但谁动了钥匙、是否错怪都未确定 |
| 自己没有多少“轻浮” | 对桂芳说，她这些年没享到多少清福 |
| 该谢就谢 | 该歇就歇 |
| 蓝色搪瓷被 | 蓝色搪瓷杯 |

六处均按原创作稿对照，是**模拟记录者的书面修订，不是真人听读确认，也不是新 ASR 输出**。实跑验证六类旧错误退出有效材料，机械厂、广州等无关信息保留，原始 ASR 与原文逐项未变。音频没有被写入或替换。

## 同模型、同问题的真实问答

使用微信 Deepseek-v4-flash，固定当前 QuotedTwin 提示与参数，改变的只有修订前后材料。三题各运行前后一次，没有挑最好的一次；这不是总体准确率评测，也不是实时延迟评测。

| 问题 | 修订前 | 修订后 | 判断 |
|---|---|---|---|
| 桂芳究竟有没有动过钥匙？ | UNKNOWN | UNKNOWN | 前后都正确，不计为提升 |
| 谁这些年没有享到多少清福？ | AIOutputInvalid | 引用修订，明确桂芳 | 一次故障变成一次可用回答；不能据此宣称稳定性提高 |
| 修车床哪里出了问题、反思了什么？ | 回答包含电击、认私理 | 电机、小螺丝、认死理及不一定都对 | 本次修订改善了词语和条件表达 |

答复里的“本人书面说明”是现有产品对 CALIBRATION 的标签；在本实验中明确对应模拟记录者修订。

## 提取改造的真实对照

冻结六段输入：四段历史实际 ASR（A01_02/06/07/08）和两段新的虚构边界文本。v4/v5 同模型交替执行，每项一次，保留所有输出。12 项提取任务中新版 6 项返回有效结构，旧版 5 项有效、1 项超时。服务成功率不作为语义准确率。

- 画笔案例：v4 的一条记忆把“可能想到小宁”写成确定的“想到小宁”；v5 保留“可能、说不清”。这是明确的局部改善。
- 桂芳/清福：v5 归属到桂芳，但仍保留错误 ASR“没想多少轻浮”。**提示词不能代替原音核对。**
- 钥匙：本次 v4/v5 都没有再加“误怪”。历史错误保留在报告，不把一次正常输出算永久解决。
- 第三方公园观察、雨天骑车例外：前后都保留了关键边界；新版仍常逐句提取，没有稳定组织成多句单元。因此只宣称接口和依据存储支持多来源，不能宣称所有跨句归纳完成。

## 判定规则

- 合理改写、代词在完整上下文里可确定，不因字面不同判错。
- 关键主体、否定、时间、条件、转述和不确定性丢失，按具体影响登记。
- 原文未确定谁动钥匙，写成“确实动过”或“被错怪”都不成立。
- 正确 UNKNOWN 可合格；超时、结构无效或错误拒答不合格。
- 结构校验仅证明引用位置/字段合法；不把 LLM 的 confidence 当事实正确概率。
- 修改提示和修改材料分成两组实验，不能混在一起归因。

## 明确未解决

1. ASR 疑词的听读核对、可直接修改完成态转写的手机版交互仍需完善；本轮使用已有记忆修订接口。
2. 六处已修复的是隔离副本，现有 ECS、手机当前数据没有自动更新。
3. 旧修订没有原始定位时，仍保守屏蔽整段；不能凭猜测补历史定位。
4. 同源重叠记忆会停用待核对，还没有自动可靠重写全部故事、条件化人物理解。
5. 事件复述去重、跨批 SUPPORT/CONFLICT/CHANGE、人工标注检索召回和大库索引仍须分批实现。
6. 六段提取与三题问答不足以证明整体质量稳定，也不算真人数字分身认可。

下一批先落实“疑词/归属核对→保存修订→列出受影响故事与理解→本人确认→同题/改写题复核”的手机操作，再扩大材料评测。用户不应承担查业务编号或重建索引的工作。
