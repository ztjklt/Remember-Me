## 2. 两个人怎么用

| 次序 | 记录者 | 亲友 | 后台与边界 |
|---|---|---|---|
| 1 | 登录记录者账号 | 登录亲友账号 | 各自真实身份与私密空间；无开发凭证入口要求 |
| 2 | 今天 → 同意录音 → 开始、暂停、继续、结束 → 试听 | 等待分享 | 原音先保存在手机，不等 AI 才确认保存 |
| 3 | 同意本段云端转写并上传 | 不可见 | ECS Paraformer V2 转写；原音及机器稿保留 |
| 4 | 档案 → 核对转写；修正名字、否定和限定；必要时“再补充一点” | 不可见 | 核对稿与书面补充独立保存，不冒充原音 |
| 5 | 确认文字与云端整理 → 查看故事、记忆、原音 | 不可见 | 微信 Deepseek-v4-flash 整理、校验证据并保存；失败保留原音 |
| 6 | 档案 → 人物 → 八个侧面、四个视图；明确同意整理并核对建议 | 不可见 | 自动结果是候选，空视图不会被假数据填满 |
| 7 | 我的 → 选择录音／已确认故事 → 预览完整范围 → 生成邀请 | 我的 → 输入邀请码 → 领取 | 领取不开放材料；邀请码默认 24 小时有效 |
| 8 | 检查接收账号名与昵称 → 批准 | 从顶部空间选择进入获授权空间 | 整段原音、核对文字、书面补充及相关记忆按预览开放；云端问答另行同意 |
| 9 | 可以继续补充 | 今天／档案找故事、播放；对话提问、打开来源 | 检索与模型输入均先按故事授权过滤 |
| 10 | 收到问题单，回答、稍后或拒绝 | 未知时提交补充请求 | 问题不是事实，生成回答不会写成本人记忆 |
| 11 | 新讲述同样核对整理，再预览并分享 | 分享完成后看到新材料 | 旧授权不自动覆盖新录音 |
| 12 | 我的 → 撤销本次分享／这段授权 | 下次检查时内容与原音受限 | 已另行保存的内容无法保证收回 |

普通账号可以成为记录者，也可以成为另一个空间的授权读者。分组只是便于团队演示，并非全局固定角色。服务端一直决定当前身份和可见材料。

## 3. 网络、证书与连接排查

服务地址固定为 `https://39.108.183.47`，API `0.7.0`，当前后台发布 `c2e17fc`。本次只改变网络入口、提供账号和更新 APK；没有把原开发目录尚未验收的模型实验部署到 ECS。

2026-10-10 用户明确批准：**App 的 IPv4 HTTPS 443 入口公开，仍限定内测账号且关闭注册**。不再要求指定校园 Wi-Fi。网络需能访问该公网地址；不能承诺所有校园网、代理或移动网络都没有额外阻拦。SSH 22、数据库及内部服务仍不公开；同机博客保留原有两个 IPv4 出口的访问边界。网络变更的备份和回退见下一节。

登录页“检查连接”会检查实际服务版本并显示结果。遇到错误：

1. 确认手机时间与网络正常，点击检查连接。
2. 证书失败：取得本页最新 APK，检查手机日期；禁止关闭 TLS 校验。
3. 版本不匹配：联系管理员，不能混装不匹配的后端和客户端。
4. 连接超时：换 Wi-Fi／手机流量交叉检查，再由管理员核查 ECS 服务、云安全组和主机规则。
5. 已连接但登录失败：核对自己的普通账号；不要反复尝试，失败请求有限速。管理员可重置账号并撤销旧会话。

IP 测试证书到期日为 **2027-01-07**。APK 只对该 IP 使用相应证书信任，不关闭验证。浏览器可能不信任此证书；本次交付入口是 APK，不将 API 地址宣传为普通公开网站。

队友有 Python 时，也可在源码根目录执行 `python tools/delivery/check_connection.py`；`--login 用户名` 交互读取密码。该命令只验证连接、登录与空间入口，不调用 ASR/LLM，也不代表整个产品验收。

## 4. 管理员维护与回退

`tools/delivery/provision_team_accounts.py` 是本台 ECS 的 root 维护工具，复用已有账号创建／密码规则。读取受限服务配置，只写 `/var/lib/remember-me/private`；重复执行校验现有映射，不重置密码或把旧空间认领给新账号。不是供任意服务器直接执行的通用脚本。账号交接文件保持私有，不上传 Git 或 Release。后续账号重置仍使用 `python -m app.account_admin reset 用户名`。

`tools/delivery/configure_ecs_access.py` 默认预览；仅支持本次已知 App／博客虚拟主机和原始网络规则，发现漂移就拒绝。已经应用后不得直接重复应用。此次备份：

`/root/remember-me-deploy/network-before-public-20261010T111431Z`

必要时关闭本次公网 App 入口：先删除新增的 IPv4 443 全网规则，再恢复该备份内两个 Nginx 配置，执行 `nginx -t` 后 reload。保留原有地址规则，不能用 `ufw reset` 清空其他服务规则。示例仅对应本次变更：

```sh
ufw delete allow proto tcp from 0.0.0.0/0 to any port 443
cp /root/remember-me-deploy/network-before-public-20261010T111431Z/remember-me-ip443.conf /etc/nginx/sites-available/remember-me-ip443.conf
cp /root/remember-me-deploy/network-before-public-20261010T111431Z/blog.conf /etc/nginx/sites-available/blog.conf
nginx -t && systemctl reload nginx
```

回退网络不删除故事、原音、账号或数据库。后台应用版本回退继续采用已有发布目录机制，与此次网络回退分开。
