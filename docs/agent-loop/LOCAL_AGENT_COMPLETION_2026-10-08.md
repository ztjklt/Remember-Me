## Task 1: 问答材料可读性与真实质量
完整授权原文仍保留，不以摘要替换，不改24000字符预算。添加从原文按查询选取的
短上下文定位片段，保留原source ID、类型、字符偏移；仅为注意力提示，不成为新事实。
先测试定位、否定上下文、同名/第三方来源和不变性，再改造。旧60题保留，重新运行
完整60题及独立改写题；逐项核对而非把HTTP成功当准确率。

实测决定：v7整批未证明改善（34支持/21需改进/5未通过，含4次请求校验失败）。
因此默认继续v6，定位提示仅在AI_TWIN_FOCUS_HINTS=true时用于明确标记的实验。
不以少数成功案例替换整批结论；保留全部原结果与逐题说明。

## Task 2: 自动关系建议，复用人工确认
兼容性新增：ProfileRefresh.kind默认candidates，可取relations；POST现有profile-candidates
下的/suggest-relations接收cloud_consent_id并排队。AI Core新增/profile-relations，
只接受服务端提供的可用候选、旧理解和原文，返回ADD/SUPPORT/CONFLICT/CHANGE建议。
结果进入既有ProfileUpdate.pending；新增nullable model_version/prompt_version与origin
字段标识系统建议，既有人工创建默认owner。源版本/候选版本两次校验，调用模型时不持锁。
CHANGE必须有原文支持的时间短语；未知ID、跨领域、失效来源、重复证据支持不得发表。
不宣称语义重复事件已完全识别，不自动合并同名人物；信息不足可返回空建议。
网页在已有候选/更新界面加入识别按钮和来源说明，继续使用现有确认/拒绝。
迁移0014先在数据库副本验证，再迁移本地运行库。旧客户端字段兼容，移动端后续
可消费同一接口；本轮新增操作先经网页与真实接口验证。
