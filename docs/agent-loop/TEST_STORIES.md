# 首轮真实模型测试材料

全为虚构测试故事。真人可以照读，但必须记录“照读测试材料”，不能称为个人真实经历。
Windows 合成语音只能证明音频管道，不能代替真人口音、犹豫或环境噪声验收。

## 每轮必查

1. 转写错字可以人工修正，机器原文仍在；确认前没有 AI Core `/process` 调用。
2. 测试记录者和读者必须是不同 token / actor；页面切换不能代替身份隔离。
3. 每份 ORIGINAL 对应有效原文，SIMULATION 有来源且明确标注；没有资料的问题返回 UNKNOWN。
4. 问“备用钥匙在哪里”，读者不能获得第二段；记录者按自己的权限能够找回。
5. 生成或搜索期间修改、删除、撤权，结果应拒绝为当前有效内容，允许明确重试。
6. 校准先保存并锁定 Twin 回答，然后才录本人回答；报告不能自动改事实。
7. 三轮重复“修改后再问、撤权后再读”，记录每次实际输入、来源、模型版本和人工判定。

只有接口返回 200 不算通过。错误引用、无依据推断、把历史状态当成当前状态都要单列。
真实模型耗时、费用和语义质量尚待密钥配置后测量，本轮没有编造这些结果。
