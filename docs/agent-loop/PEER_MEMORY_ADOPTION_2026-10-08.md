# 同学记忆与人物更新结构：采用边界及补充方案

依据固定提交8627f03的 services/ai-core/app/agent/orchestrator.py、packages/contracts/remember_contracts/agent.py、docs/architecture/AGENT_CORE_LOOP.md，对照本地db6a0ce及10月8日增量。这里的“没移植”不等于“没有价值”。

## 结论

完整ADD/SUPPORT/CONFLICT/CHANGE值得采用，特别是支持证据积累、未解决矛盾和随时间变化。当前只吸收了原文材料解析、情境、支持/反例、人物候选、问答和先锁后答等部分；**尚未采用同学完整的增量Trait状态机**，不能把已有字段说成等价实现。

先前没有直接移植的理由：同学以snapshot revision和自动Persona更新为核心；本地已确定一个共享事实库、Owner确认、故事级授权、撤权与生成后版本校验。直接移植会引入第二套事实/确认规则，或让模型自动修改用户已经确认的理解。因此应适配规则，而非复制整套运行路线。

## 逐项映射

| 同学结构 | 本地已做 | 需要补齐 |
|---|---|---|
| ADD，新情境/新理解 | 生成带来源的pending候选，确认后用于问答 | 明确记录新增动作及理由，避免反复生成等价候选 |
| SUPPORT，同结论同情境 | evidence_ids及去重后的材料计数 | 为已确认理解追加“支持建议”，确认后关联新证据；不因两段录音自动提升为稳定人格 |
| CONFLICT，保留矛盾 | counter_evidence_ids，来源/修订记录 | 持久化未解决冲突关系、指出双方具体内容；Planner一次提出一个中性核对问题 |
| CHANGE，明确变化 | 事实层supplement/correction/change，保留历史及时间说明 | 人物理解层新旧版本链接和适用时间；必须由Owner确认，不能与纠正旧错误混同 |
| 原文优先/局部冲突 | effective_materials读取有效核对原文，不只读取摘要 | 继续检查无关事实是否被误抑制；Reader的完整旧音频涉及失效事实时仍按现有分享粒度拒绝 |
| Snapshot revision CAS | source_basis及生成后短事务复核 | 后续人物动作也必须进入同一来源/权限版本体系 |
| 自动校准回写Persona | 锁定答案、实际比较报告 | 有意不自动回写：报告只能提出待确认建议 |

## 需要保留的细节

1. 四种动作是“人物理解的更新动作”，不代替记忆内容类型，也不把模型变成四个互相对话的Agent。
2. 来源、叙述发生时间、模型观察时间要区分。模糊日期不编造；“后来改变了”与“以前说错了”不同。
3. 同学SUPPORT使用多Episode判断支持数量。本项目不能直接把两段录音当两次独立经历：第3段是重复讲述，不应增加人格确信度。允许显示“多次提到”，不宣称独立事实验证。
4. 新录音默认私密。Reader的人物视图和关系只能从可见材料计算，不能泄露Owner私人反例或“还有一条秘密证据”的内容。
5. 冲突只影响相关结论。不能因为一句话冲突而让无关问题全部UNKNOWN。但读者获准的是完整原音：若音频仍包含已失效、未获准更新的说法，不能借“不抑制原文”绕过权限。片段级播放需另有可靠时间对齐和授权，不在本轮伪造。
6. CHANGE建议应验证目标仍有效、同Subject、同Domain/情境、证据来源和版本；确认后旧理解退出当前问答，历史保留。

## 后续落地资源提案（不是已经实现）

在现有ProfileCandidate体系追加人物更新建议资源：action、target_candidate_id、reason、support_evidence_ids、counter_evidence_ids、time_text、base_source_version、pending/confirmed/rejected。确认端执行动作，不直接接同学自动快照替换。历史动作留存，重放幂等；资料/授权变化时提议失效。迁移按当前末端追加；对外接口先更新API提案再接双端。

不能在未经确认时让候选自动覆盖旧理解；也不能为展示完整状态而悄悄重分类旧的真实测试数据。这轮先用30段真实处理材料检验上述边界，再针对暴露的问题实施增量，而非把“移植了更多代码”作为完成标准。

## 本夜验证怎样覆盖这些问题

- ADD：新人物、日常经历与明确偏好；保存来源，不补全没讲的事实。
- SUPPORT：反复出现的价值/表达与重复讲述；检查是否误计独立事件。
- CONFLICT：未核实年份、同名人物、否定、不确定与第三方转述；不得自动合并。
- CHANGE/纠正：第4段本人明确纠正、第5段时间变化；前者关联旧记忆，后者若没有先前对应住址记忆，仅保留叙述内的前后时间，不虚构修订目标。
- Reader请求：第9段先留问题，第10段录音回答先私密；未分享不得进入Reader问答。

原始音频、ASR、确认稿、提取、人物候选及问答各自留档。人物候选不是心理诊断；本夜技术扩充不等于人工听读或临床使用验证。
