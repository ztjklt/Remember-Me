## 2. 事实与权限规则

- IMPORT、ANDROID_MIC、IOS_MIC 都在真实转写后等待核对；原音、机器转写、确认文字分别保留。
- 问答接收获授权的有效全文、记忆证据及本人确认的修订；原文逐段扣除已失效范围。无法安全分离时抑制整段原文。
- 待确认修订原文不能抢先进入问答。读者不可通过受影响旧故事的全文、音频或检索复活失效事实。
- 有效全文上限24000字符，含重叠证据的输入总量也校验；超限明确失败，不偷偷截断。
- 人物归纳是持久后台任务，结果先为候选，确认后才供本人问答使用。读者视图只依据可见材料。
- 重复完整讲述做规范化精确去重；“去重材料数”不证明语义上独立的经历或印证。
- 模型调用不持有写锁；返回后短事务检查来源、人物理解和权限版本。变化返回SOURCE_CHANGED，不暗中重调。
- TwinAnswer持久保存source_basis；旧答案读取再次检查。迁移前旧答案无此依据时保守标为陈旧。
- 原文片段可播放完整原音；核对文字并非已验证的音频逐字对齐，不输出伪造时间戳。

新增迁移0009（人物候选及任务）、0010（答案来源版本）在已有库副本执行并通过integrity_check，随后应用本机库；备份保留于backend/var。
接口细节见[API.md](API.md)，启动与旧空间所有者映射见[RUNBOOK.md](RUNBOOK.md)。
