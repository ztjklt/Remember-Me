## 差异与做法

浏览器检查发现 v21 花朵标签为 91% 乳白填充、缩放栏为 86%，底部导航因旧媒体规则实际为不透明白色，且这些位置的背景模糊没有启用。这些叠层把风景洗白了。

本轮新增 `nature/material-v22.css` 作为统一材质层：

- 紧凑标签、缩放栏、换景控件、底部导航、首页记录卡片、个人页功能卡片使用草木色薄玻璃。基础染色为 `rgb(40 60 47 / .42)`，顶部仅 3% 淡光渐变；夜景使用偏青的深绿底色。
- 使用 `backdrop-filter: blur(16px) saturate(1.14) brightness(.57)` 处理实际背后的画面。模糊去掉细碎干扰、染色保留绿与蓝、轻微明暗边缘说明厚度。文字没有一起降低透明度，也没有对整个控件使用 `opacity`。
- 使用统一浅色文字和细边框；选中导航以更深的通透底和亮边区分，保留滑动反馈。首页图标改成适合深色玻璃的浅色，避免原来的深蓝难以看清。
- 正文、播放器和重要说明使用更稳的淡鼠尾草色衬底，减少奶白填充；不把长篇文字直接放在高对比花纹上。
- 花瓣标签缩减厚重留白，三条回忆使用小数字徽标，完整“3 个片段”继续保留在可访问名称与列表中。微调五个标签的位置，避免遮挡邻近文字。
- “通透预览”明确展示材质；“跟随系统”尊重减少透明度偏好，“清晰实色”和不支持模糊的浏览器退为同色系实色。高对比偏好保持实色。

本轮沿用已有图片、花朵几何、镜头与场景库，没有新增生图、原生功能或共享协议变更。材质不会改变记忆的分类和来源。
