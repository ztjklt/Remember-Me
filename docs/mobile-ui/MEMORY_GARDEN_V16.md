# 镜头，轻轻走近 · v16

2026-10-02，按用户反馈替换 v15 的花朵飞行和轮廓拉伸转场。入口：[本地手机演示](prototype.html?demo=1#archive)。用户明确要镜头移动到花朵所在的位置，花本身保留在花园空间里。

## 问题与改动

v15 花朵是用 `transform:translate(-50%,-50%)` 定位的按钮，原型通用 `button:active` 会以更高优先级把它覆盖为 `scale(.985)`，失去居中偏移，产生右下跳动。另外，转场会重建场景、复制花朵到固定层，单独移动花，而标题/画布尺寸也发生改变。

v16 的花朵放在固定世界坐标的容器中，点击区与绘图分离，定位使用独立的 `translate` 属性；按压仅轻微改变明暗。花丛与花朵层共用同一个 `depth-stage` / `depth-world` DOM 节点，不重新生成花瓣，不改花在世界中的位置。标题区域等高，筛选浮层不推动画布。

所有花朵、枝条和叶子接受同一个父级相机变换，统一坐标为 360×420。主镜头约 620ms：焦点快速趋向中心，放大稍晚完成；无弹簧、过冲、先退后进。周围花朵渐隐，焦点花的标签在镜头落稳后显现。返回恢复原镜头；打断时读取当前实际变换矩阵，从当前画面接续。键盘、按钮、滚轮和双指几何共用新相机模块。

进入花瓣时，保留原场景短暂继续靠近选中区域并淡出，正文轻淡入；取消了 96 点轮廓逐帧拉伸。阅读底衬重画为浅缺口、不对称弧边、微弱叶脉与灰蓝至奶油色的半透明底。内容卡片保留完整圆角和清晰文字。

## 技术依据

- [D3 zoom interpolation](https://d3js.org/d3-interpolate/zoom)：将视图表示为中心与可见范围，采用镜头而非物体飞行的思路。本版没有引入 D3 依赖，也没有直接使用可能先缩远的通用飞行轨迹；为这三层设计了焦点单调靠近的轨迹。
- [web.dev 高性能动画](https://web.dev/articles/animations-guide)：主动画只改变 `transform`，辅助淡入改变 `opacity`。预计算 91 个相机关键帧，交给 Web Animations API 执行；正常演示没有逐帧 JavaScript 样式写入、SVG 轮廓重画或尺寸测量。
- [W3C CSS Transforms](https://www.w3.org/TR/css-transforms-1/)：各关键帧保持同一变换列表与固定原点，避免来源/目标变换格式不同导致的矩阵分解路径。

屏幕投影为 `screen = center + (world - center) × zoom + translation`。先让所选世界点的屏幕投影单调靠近目标，再由当前倍率反解相机平移。因此周围物体保持同一空间关系，焦点不会因独立平移与缩放混合而先向外走。

## 已验证

`node --test docs/mobile-ui/memory-garden/camera.test.cjs docs/mobile-ui/memory-garden/depth.test.cjs docs/mobile-ui/memory-garden/garden.test.cjs docs/mobile-ui/memory-garden/imagery.test.cjs`：20/20 通过。新相机测试覆盖三处焦点的单调性、同一投影保持空间关系、打断后起点连续、360×420 下双指/滚轮锚点保持。

Windows 浏览器实测：

- 三朵花各自进入；实际计算样式采样为 76、68、74 个记录（含端点），焦点到中心的距离均无反向增加（0.05 世界单位容差）。[轨迹原始记录](media/garden-camera-v16-verification.json)保留矩阵换算结果。这是轨迹证据，不是手机帧率成绩
- 花丛/花朵共用场景节点；厨房进入前后画布矩形一致；连续进入/中途返回、按钮返回与已有浏览器历史路径可用
- 搜索“便条”仍显示一朵花、一个匹配片段；雨夜“借伞与回应”仍能阅读三条原稿摘录
- 播放、循环、返回后暂停正常，离开时音频 `paused=true`
- 390×844 手机画布、358×843 窄屏无横向溢出；窄屏花瓣标签约 48px 高
- 深色 + 200% 文字 + 减少动态使用同一层级列表并能进入阅读页，无溢出/遗留转场层
- 1645px 宽屏的阅读页保持双栏；检查时未发现页面控制台错误

诊断 URL 可加 `&motion-check=1`，仅此模式逐帧读取实际矩阵并把记录附在世界节点的 `data-motion-report`。普通演示不运行采样。截图：[花丛](media/garden-clump-v16.png) · [聚焦花朵](media/garden-flower-v16.png) · [花瓣阅读](media/garden-petal-v16.png)。
