2026-10-02，按用户对首页云朵、句号与花图形态的反馈继续优化。本轮只改本地网页原型，未修改 Android/iOS、共享 Contract、录音和模型处理链路。

## 首页

增加两层透明云图，在原来静态天空与草地上缓慢位移。近层 38 秒、远层 57 秒往返，偏移范围不同，不移动文字或整张风景。位移只用 transform，云层不接收点击。页头可暂停/继续；离开首页、页面隐藏或开启减少动态后停止。开启减少动态时控制显示“静止云景”。

移除首页“慢慢留下来”“不必整理好思绪”“一件小事，也可以慢慢说”末尾的句号，保留逗号和分行。档案引导短句同样去掉末尾句号，原稿引文的标点不改。

透明云图为内置 imagegen 新生成素材，保存于 [cloud-bank-v13.png](nature/cloud-bank-v13.png)。原图 1942×809，保留 alpha，抽样 alpha 范围 0–253，存在半透明边缘。完整生成提示词、文件摘要见 [cloud-asset-v13.json](nature/cloud-asset-v13.json)。原始草地背景没有改图，生成图层本身不是天气数据。

## 记忆图

去掉 v11/v12 的五个大椭圆式轮廓。沿用 [品牌 v2](../../assets/brand/forget-me-not/v2/svg/mark-light.svg) 花瓣的曲线形态，以代码绘制 3 朵不同大小、角度的花，共 15 片花瓣。加入瓣缘缺口、浅色细脉、暖金花心、弯曲茎和叶片，不使用重复圆形拼花。

630 个确定性细点落在花瓣内部，提供点绘肌理；它们没有事件、标签或记忆内容。15 个可交互亮点继续引用原有 E01–E03 示例记忆，颜色表达原有人工主题标签。默认隐藏连线和浮动标题，选中时显示原话与同源故事关系，避免把整朵花变成被文字遮挡的网格。

增加“星丛”作为不用花的对照：330 个装饰星点与 15 个交互记忆点，在同一内容、浮窗、场景、音频和意象选择逻辑下使用更自由的空间布局。花枝更贴合品牌；星丛给关系与后续聚合留下更大空间。本轮没有扩展为数百条虚构内容，也未声称完成大数据量交互或粒子性能验收。

两个布局均使用稳定位置，不在每次返回时随机跳动。保留平移、缩放、列表、来源浮窗与场景返回；切换图形样式时归位，进入场景再返回保留当前样式和选中点。两边最外侧的花图光点向内调整，保证窄屏完整触控范围。页面转场保留独立的 SVG 渐变引用，避免原页面移除后花瓣在退场快照中丢失填色。

## 实际验证

- `node --test docs/mobile-ui/memory-garden/garden.test.cjs docs/mobile-ui/memory-garden/imagery.test.cjs`：12/12 通过。扩展现有几何检查，两个布局在 320px 手机布局假设下，48px 圆形目标完整落在画布内、互不重叠，所有关系线仍只连接同一故事。
- 浏览器中读取到云层 transform 随时间变化，静态背景不变；手动暂停后跨两次观察 transform 完全相同，继续后恢复，离开首页后 paused。
- 纯净预览内容画布为 390×844；本轮窄视口实测为 325×844（浏览器缩放换算后的实际 CSS 尺寸），首页、花图与浮窗无横向溢出。不要将工具请求的物理尺寸当成 CSS 实测尺寸。
- 深色、200% 文字、减少动态组合下，首页及花图/浮窗无横向溢出，云层 animation-name 为 none，继续按钮禁用并说明静止原因。
- 实际 DOM 为 630 个花瓣细点、15 个可交互亮点。星丛点选、进入场景、返回后仍为星丛并保留 m1；放大到 125% 可用。旧 v12 意象选择逻辑保留。
- 两个最终预览标签无浏览器 error 日志；JS 语法与 diff 空白检查通过。未进行 Android/iOS 构建、真机手势或原生性能验收；所有结果为本地网页层。
