# 一片花瓣，慢慢展开 · v18

2026-10-02，按用户反馈继续改善枝干厚度、自然弯曲，以及花朵到花瓣阅读页的连续性。[从单花开始体验](prototype.html?demo=1#archive/E03)。

## 改动

**枝干。** 新绘制有粗细和明暗的弧形枝条，世界坐标中的半宽从基部约 3.27 渐变至花端 0.82，比 v17 更有支撑感。各枝的弯向、幅度不同；叶柄、节位、细分枝与小花苞均从同一条主干曲线上取点，避免连接脱离。聚焦单花时仍只保留本枝，花的位置和既有相机逻辑不变。图形是自然风格插画，弧度有艺术化夸张。

**花瓣展开。** v17 把整朵花淡出，再显示另一张固定形状的纸底，视觉身份在中间断开。v18 从实际被点击的花瓣取得轮廓、纹理和屏幕变换；阅读页直接使用这片花瓣的同一条 SVG 路径，延展为首屏暖色底衬。每片花瓣进入后保留自己的微小形状差异。

约 740ms 的展开分工：原场景逐渐退去，花瓣连续靠近、转正、伸展；冷蓝材质渐变为奶油纸色，内容在后半程出现。变换按锚点、旋转和正比例缩放插值，避免直接混合相反矩阵让花瓣在中途塌缩。预计算 91 个 transform 关键帧交给 Web Animations API，正常演示不逐帧重画 SVG 路径。渐变通过同一几何位置上的两种材质叠层完成。

返回时同一花瓣收回原位。中途立即返回会保留当时的矩阵、颜色混合及旧画面透明度，再从该状态接续，而非先跳到阅读页终点。离开档案、改变视口、减少动态或进入后台会结束并清理临时层；播放状态仍由原音频逻辑管理。

**其他切换。** 首页 / 档案 / 我的等页面、花园 / 录音分栏、花园 / 列表，以及列表层级进入阅读页，共用短暂的旧画面快照柔和过渡。旧背景和滚动位置在过渡期间保留，云层快照冻结在当下位置。底部导航节点不重建，选中块继续滑动。减少动态时保持短淡入或直接更新，不展开花瓣。

- “不一样，也喜欢”完整展开 / 收回；实际采样分别 89 / 80 条，两端 SVG 路径完全相同。最终变换矩阵与实际目标的最大分量误差分别约 0.00036 / 0.00040，交接后恢复真实底衬，没有遗留过渡层
