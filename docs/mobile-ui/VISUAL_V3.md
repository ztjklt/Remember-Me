# 第三轮：组件细节与留声蓝花

用户反馈：前两版的小组件、字体与方块背景仍显粗糙，缺少成熟手机产品的整体感。本轮从字号、列表和控制器重做视觉关系，不改变录音、核对、来源及授权流程。

## 参考与转化

| 公开项目 | 已查看材料 | 用于本项目的设计判断 |
|---|---|---|
| [Pocket Casts Android](https://github.com/Automattic/pocket-casts-android) / [iOS](https://github.com/Automattic/pocket-casts-ios) | 官方仓库、产品截图、Android MiniPlayer 与对应布局 | 播放/暂停是稳定的主控制，标题、进度与时间分层；避免让播放控件变成装饰卡片 |

| [Moe Memos](https://github.com/mudkipme/MoeMemos) | 官方 README、MemoView 源码与产品截图 | 使用原生导航与可缩放系统文字；内容编辑、状态反馈和日常浏览保持同一层级体系 |

以上是视觉和交互参考，没有复制第三方源码、图标或字体；没有把这些应用安装运行后的表现冒充为本次观察。Pocket Casts / Moe Memos 为 MPL-2.0，Read You 为 GPL-3.0；以后若采用实际源码，应另核对对应文件许可和义务。本轮使用的图形来自用户提供的本地品牌包。

## 实施内容

- 白色/近黑主背景，浅中性播放器面；蓝色用于主操作与选中状态。
- Android/原型页面标题 26、分区 18、正文 17、辅助 14；取消大面积粗体。iOS 继续使用 Dynamic Type 的系统样式。
- 首页保留一个 56 高录音入口，最近记录为分隔列表；移除声音刻线装饰与图标底块。
- 原型提供“组件对照”页，可单独观察文字、记录行、播放器、按钮与错误提示。
- 播放器使用 48 圆形播放控制、真实状态接口、独立进度与时间。HTML 原型仍是明确标记的模拟播放。
- 录音电平改为横向区域；原生电平来源未变。花形标识不充当声量或处理进度。
- 记忆采用正文、证据与原音入口的阅读顺序，减少同级容器。

## 品牌接入

接入的是本地交付包 `assets/brand/forget-me-not/v1` 中已批准的 **C / 留声**：五瓣蓝花、金色花心。未找到另一个能独立确认的“忘忧花”版本，未自行混合两种标识。

- 顶栏 32、来源处 24：简化路径，浅深色对应。
- 空状态 80：材质版；有邻接文字时标识为装饰，避免读屏重复。
- Android：用户提供的 Compose 路径组件、材质 PNG、带安全边距的前景和单色自适应启动图标。原始用户素材保持不变。
- iOS：用户提供路径的 SwiftUI 适配、材质 imageset、浅/深色 AppIcon。
- Web：仅复制需要的三张 SVG 到 `brand/`，不依赖外网字体或远端图片。
