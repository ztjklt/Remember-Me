# 第四轮：雾光背景与按压反馈

用户要求减少纯白，不使用单一平涂背景；渐变需要有蒙版与层次，按钮需要明确的点击反馈。本轮保留第三轮字体、列表和品牌位置，集中修改材质。

## 构成

- 静态底色：雾蓝、灰紫、暖沙三个相近明度的颜色场，避免大跨度彩虹色和硬边光斑。
- 内容蒙版：从上方较透到下方接近背景色，降低长列表区域的色差。蒙版不拦截交互。
- 阅读表面：输入框、原文和播放器使用带颜色的稳定背景；Web 导航局部使用透明表面与模糊，Android 用原生表面，不模拟玻璃模糊。
- 按压反馈：Web 主按钮变深、位移 2px、缩放 0.99、阴影收拢；Android 保留 ripple，加深渐变并降低阴影；iOS 保留系统点击语义，叠加按压明暗与阴影变化。释放恢复，无常驻流光。
- 减少动态时 Web/iOS 取消缩放与自定义动画，保留颜色反馈。Web 减少透明度或增强对比度、iOS 对应辅助设置下使用有色实底。Android 背景本身为不透明绘制。
- 不增加录音开始触觉，不使反馈声音或震动污染录音。

## 色值

浅色背景基底 #E4E9F2，阅读面 #EDF0F6，辅助字 #536176；颜色场 #D7E3F3 / #E6DFF0 / #EEE5DE。深色基底 #171F30，阅读面 #232D40；颜色场 #22324B / #302B43 / #202C34。色值集中在 tokens.json，基础色同步到两端主题。

Web/Android 主按钮渐变浅色 #4266BC → #344DAA，深色 #B8CCF4 → #A3B7E8。iOS 主按钮采用现有语义主色叠加 10% 高光与按压暗面，适配既有自定义操作颜色。
