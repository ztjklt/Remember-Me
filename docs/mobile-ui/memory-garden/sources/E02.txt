二〇一七年冬天，小雨刚开始上班不久，我们说好周五晚上一起吃饭。她提前订了靠窗的位子，还发照片给我看菜单。我本来六点就能走，临下班同事有事请我帮忙收一批还回来的书。我想着不过十来分钟，连消息都没认真回。等我把书分好、登记完，天已经黑透了，手机上有她的两个未接来电。我赶到店里时，她已经吃完了，只给我留了一小碗汤。她说没关系，可我看见那碗汤都凉了，心里一下就难受起来。我后来向她道歉，她没有跟我吵，只说下回如果来不了，早点告诉她。我那晚原想解释同事有多忙，话到一半停住了，因为她并不是怪我帮人，而是不知道要等到什么时候。那天之后，我不敢说自己再也没有失约，但我开始把和她的约定写在日历上。我们还说，哪天都不用赶时间，就一起去看她一直想看的画展。后来那顿饭的味道我记不清了，倒是一直记得她把冷汤推到我面前的动作。
