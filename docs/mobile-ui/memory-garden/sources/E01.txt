我叫林岚，在社区图书馆工作了很多年。二〇一六年秋天有个下雨的晚上，我值晚班，关门的时候才发现阅览室里还有一位老人。他在窗边找伞，找了半天，最后从书包里摸出一张借书证，笑着说自己把伞忘在家里了。我把柜台后面那把备用伞借给他，等他走到街口，才把卷帘门拉下来。那天小雨给我打过电话，问我怎么还没回家，我说再等五分钟，结果等了差不多半个小时。我回到家，鞋边都是雨水，她已经把饭菜盖好了，还问我要不要再热一遍。后来我一直记得那盏靠窗的灯，还有雨点打在铁门上的声音。我喜欢图书馆里有人愿意慢慢读书的样子，不过说实话，晚班结束以后，我也想早点回家。那会儿我总觉得自己还能多做一点，家里的人会理解。现在回头看，理解不等于他们不会等我。第二周那位老人来还伞，带来一张写着“谢谢”的便条，我把便条夹在值班本里放了很久。
