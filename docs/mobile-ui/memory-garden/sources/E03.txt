二〇一八年春节前，我想照着妈妈手写的小本子做一锅萝卜汤。那本子边角都卷了，第一页写着菜名，后面却没写几克几勺，只有一句“火别太急，等汤自己变甜”。这是妈妈的话，不是我发明的做菜道理。我第一次照着做，嫌慢，把火开大，汤是白了，萝卜却还硬着。打电话问她，她在那头笑，说我小时候也是这样，什么都想快一点。我当时不太服气，第二天还是重新买了萝卜，守在锅边等。厨房里都是热气，玻璃上起了一层雾，我用手指在上面画了个小圈，看看窗外是不是快天黑了。后来小雨来吃饭，说味道跟外婆做的不完全一样，但她喜欢。我现在做这道汤，还是会想起妈妈那句提醒。可别把它说成什么祖传秘方，它就是我们家一个普通的做法。我留下这段记忆，是因为那天我第一次愿意为一锅汤慢下来。后来我把那句“火别太急”誊到新卡片上，但旧本子没有扔。
