# 花，慢慢长成自己的样子 · v17

2026-10-02，沿用已确认的三层记忆花园与 v16 连续镜头，集中优化枝叶、花瓣、触控和绘制负担。[手机演示](prototype.html?demo=1#archive)。

## 花与枝叶

参考已有 [Myosotis sylvatica 实物照片](../../assets/brand/forget-me-not/v2/reference/myosotis-sylvatica.jpg) 和 [NC State Extension 植物资料](https://plants.ces.ncsu.edu/plants/myosotis-sylvatica/)，保留五瓣灰蓝花冠、小黄眼和窄叶的识别特征。原创 SVG 是温柔的植物插画表达，不是写实照片或植物学复原。

- 每片花瓣有确定性的长度、左右宽度、弯曲和角度差异；弧边带浅缺口、轻翻边、细脉和弱纹理。刷新不会重新随机变形
- 黄眼改为较小、连续的环状花喉，减少原先“花心里又开一朵小花”的感觉
- 每朵花拥有独立的渐细弧形花梗，直接连接它在花园中的坐标。三片大小不同的窄叶沿同一曲线交错生长，不再使用整组共用的大叶与空枝
- 修正全局图标 SVG 描边被枝叶继承的问题；画布底缘轻淡出，避免花梗像被齐切一刀
- 走近单花时，只保留对应枝叶，其他枝叶随花朵退去，世界坐标与 v16 镜头算法不变

## 体验与绘制

- 花瓣标签的字号、颜色和触控面积更清楚；弱化“待绽放”，保留完整花瓣轮廓
- 搜索增加 44×44 的清空按钮，清空后保留情感筛选、恢复输入焦点与相机归位；修复刷新结果后搜索按钮展开状态不一致
- 筛选选择后收起，点击外部或 Escape 也能关闭并保持场景；Escape 可先清空搜索，再收起搜索栏
- 实色阅读偏好覆盖花瓣标签和阅读卡片，深色及减少动态继续可用；200% 字体沿用层级列表
- 细点合并成 SVG 路径，绘图按组缓存。相同厨房花朵的绘图元素由 290 个降到 91 个（约减少 69%）；字节数由 16,881 到 16,468，主要收益是减少 DOM 元素，不是大幅减少下载
- 仅镜头移动/拖动时申请 `will-change: transform`；非首页或文档进入后台时暂停云层并释放其提示，声音仍由用户播放控制

没有新增渲染库、粒子计时器、模型调用或外部资源请求。淡出蒙版仍有合成成本，元素计数不代表真机帧率提升。

Windows 浏览器实际检查：

- 花丛 → 厨房花朵 → 妈妈的小本子 → 回听/循环 → 返回；播放时 `paused=false`、`loop=true`，返回后 `paused=true`，无遗留转场层

- 筛选外部点击、Escape 关闭，搜索清空后展开状态正确；花丛/单花切换保留同一个世界节点
- 单花实际枝叶透明度为所选 0.67、其余 0，枝叶描边为 none；不再留下其他花的空枝
- 390×844 手机画布以及 358×843 窄屏无横向溢出；窄屏花瓣标签约 48px 高、88–108px 宽（不含禁用标签）

- 首页云层为 running；进入档案后 paused 且 will-change 为 auto。首页原有 68% 卡片填充、四角 26px 圆角保留
