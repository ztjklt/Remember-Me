# 第五轮：精修首页、档案与播放器

按用户批准的范围保留第四轮配色、花形和数据流程，集中优化三类组件。

- 背景光感向左上方集中，右侧灰紫范围缩小；背景蒙版在页面下部更早收敛，减少列表阅读区色差。按钮阴影减轻，光源方向保持一致。
- 首页缩短重复纵向间隔，原音说明靠近录音按钮；待处理记录形成紧凑的动作行。iOS 保留已有问题功能，并将它放在最近记录之后。
- 列表使用统一的音频图标、标题起点、元数据与箭头对齐；待核对和失败状态突出，完成状态降低存在感。Web 将日期、时长、状态放入可换行元数据行；iOS 没有可用时长字段，因此不补造时长。
- Android/iOS 播放器统一为左侧标题和真实状态、右侧播放键，下方进度及时间；加载时禁用播放并显示加载反馈，原有错误路径保留。iOS 只有载入真实音频后才显示可定位进度。
- Web 进度轨道变细、交互区域仍为 44px；支持键盘定位，暂停切换保留焦点，播放结束保留终点，重新播放从头开始。Web 始终明确标记为模拟播放。
- 点击行保留局部着色反馈；Android 沿用 ripple，iOS 使用统一行按压样式。减少动态设置继续生效。没有持续装饰动画或假音频波形。
