# Android 下一版：真实花田与日常设置

日期：2026-10-10，北京时间。状态：**设计评审稿，尚未实现、未构建新 APK、未部署新服务。**

基线：`codex/team-handoff-20261010@13280fe`；当前下载包为 `0.7.1-internal`。本规格承接用户认可的自然视觉、花田—花朵—花瓣浏览及双角色流程，不把旧网页预览当作 Android 实跑结果。

## 1. 这一版交付什么

让记录者整理完成后能在手机花田找到故事，展开记忆花瓣、阅读来源并播放原音；让亲友获得授权后拥有同样清楚的浏览入口。同时把“我的”整理成日常设置，使主题、设备权限、内容授权和账号操作都有明确位置。

保持“今天／档案／对话／我的”导航，保留真实录音、转写核对、书面补充、问答、邀请及撤权的既有行为。花田是浏览方式，不是另建的事实库，不改变 Agent 提取、审核或授权规则。

## 3. 实现路线选择

推荐原生 Compose：沿用 `NativeWorkbenchModel` 和登录、播放器、权限校验，新增独立花田展示组件与设置页面。它可以共享现有会话及原生返回行为，也能接入 TalkBack、大字号与减少动态效果。

WebView 直接装入旧原型会引入固定故事、第二套播放器以及身份和返回状态的桥接；仅展示网页或截图则不能满足“安装后能用”的目标。本版不采用这两条路线。原生版继承旧设计的构图、花影、色彩与递进含义，不宣称像素级复刻网页全部连续镜头。

## 4. 花田的数据规则

花田使用现有 `/api/v1/workbench/subjects/{subject_id}/stories` 与该空间的 `/narrative` 响应；以服务端返回的可见集合为上限。客户端不请求所有人的材料再自行隐藏。

- 已确认、`source_valid=true`、`kind=story` 的故事组织记录形成故事花簇，键为真实 `record.id`。跨录音关联只有在本人已确认时才成立。
- 已完成、已核对、未标为不可用的录音即使尚未组织，也能进入“尚未归组的记录”，以真实 `episode_id` 显示；不能声称它已经被 Agent 关联成跨录音故事。
- 已保存但未转写、待核对、失败或待整理内容放在独立的“待处理”入口，不开出代表成功记忆的花。没有记忆时明确说明，不生成装饰性内容冒充成果。
- 花瓣绑定 `memory_item_id`；仅展示当前有效记忆。已组织故事通过**实际证据 ID**关联记忆，不能因为两条内容来自同一段录音，就把它们全部塞进同一个故事。
- 没有匹配记忆、但存在有效故事证据时，提供“故事依据”入口，绑定实际 `evidence_id`，标明是核对文字依据，不能伪装成新提取记忆。
- 一条记忆可以在多个有证据关联的故事中出现，但同一簇内按 ID 去重；不重复保存事实。
- “八个内容侧面”作为筛选与花瓣信息标签，不强行填满八格。内容很多时按稳定 ID 分页，每组最多五个花瓣，并提供同等内容的列表入口。
- 花朵标题使用本人已确认的故事标题；未归组录音使用现有 `storyTitle`。没有可靠标题时显示讲述日期，不在渲染时偷偷调用模型命名。
- 旧示例的 E01–E03 音频、故事、意境图和固定花瓣不进入正常模式。自然背景可以复用，示例人物图片不能自动成为真人故事封面。

### 浏览与返回

“档案 → 记忆”默认显示花田，顶部保留花田／列表切换、搜索、筛选以及“了解这个人”。点击花簇后展开故事标题、讲述日期、来源录音数和可点的花瓣；点击花瓣进入稳定背景的阅读页，显示正文、来源类型、证据与“播放完整原音”。多来源时先列出真实录音，不默认假装有精确片段定位。

首版使用纵向可滚动花田、分组分页和聚焦展开，不要求用户掌握双指缩放才能找到内容。选择故事和展开花瓣使用可打断的过渡；减少动态效果时直接切换。旧网页的自由拖动、连续镜头与视差保留为后续增强，不作为首版交付前提。

返回时恢复筛选、列表位置、当前花簇和花瓣页码。保存的是浏览状态与 ID，不另存私人正文。恢复前验证 ID 仍在当前可见材料中；已撤权或来源失效则关闭内容，显示更新原因。账号、空间变化后清除上一身份的花田内容和导航状态；迟到响应仍由现有 `SessionGate` 拒绝。

从花簇发起分享时，仍调用既有完整分享预览，列出涉及的每段原音和核对文字。花瓣不能绕过整段录音授权，不能只以当前显示的一句摘要说明分享范围。

## 5. “我的”与设置结构

| 页面入口 | 实际内容与操作 | 保存位置 |
|---|---|---|
| 账号与空间 | 当前昵称、当前空间、记录者／亲友角色、切换空间、换号、退出；登录失效回到登录 | 身份由服务端解析；设备会话继续用 Keystore 加密 |
| 外观与阅读 | 跟随系统／浅色／深色；按页面自然场景／草地／湖畔／林间／海边；简化花田动效 | 仅本机非敏感偏好；重启保留，默认跟随系统 |
| 设备权限与提醒 | 麦克风授权状态、通知授权状态、系统权限入口、默认关闭的每日提醒 | 权限读取 Android 系统，提醒沿用已有本机机制 |
| 亲友与分享 | 邀请状态、已确认亲友、开放的完整录音范围、是否允许云端问答、撤销 | 现有服务端邀请和故事授权，不增加第二套授权 |
| 我的用词 | 常用人名、方言解释及保存；说明需在核对时明确带入相应故事 | 现有空间用词接口 |
| 待处理 | 待核对录音、处理失败、亲友问题、待审核人物理解及故事关联 | 现有真实任务和状态 |
| 数据与帮助 | 原音／机器稿／核对稿／书面补充的区别；当前版本与连接检查；清理下载缓存 | 清理仅针对可重新下载的来源音频，保留手机未上传原音和凭据 |

主题改变只调整呈现，不能改变角色、开放注册、扩大分享或触发模型调用；不重启正在进行的录音、上传或整理任务，不丢失核对中的文字。文字使用系统字号缩放，不添加独立的字号滑块来覆盖系统无障碍设置。

系统权限与业务同意分开：麦克风获准不代表同意上传、ASR、云端整理或亲友分享；关闭设备麦克风不等于撤销已经共享的故事。提醒关闭必须取消已有调度，不能仅把开关画成关闭。

退出时停止播放，清除可见业务内容与可重新下载的来源缓存，撤销当前服务端会话；断网时明确提示仅完成本机退出，服务端会话将在到期后失效。录音中退出先完成并保存，正在核对的未提交文字先提示本人处理，不能静默丢弃。换号先退出，不让两个身份共用旧的花田详情或播放请求。未上传本机原音继续按原账号隔离保留，不随缓存清理丢失。

公开演示账号不等于个人私有账号；试用说明继续明确只适合虚构素材。账号自助改名、修改密码、全设备登出与注销需要兼容接口提案和独立验收，不由本版设置 UI 凭空实现。

## 6. 组件与代码边界

围绕现有入口增加 `MemoryGardenScreen`、`GardenProjection`、`MemoryPetalReader`、`AppSettingsScreen`、`AppearancePreferences` 和系统权限状态读取组件。它们是拟定的组件职责，不代表文件已经创建。

`GardenProjection` 只把已有可见数据映射成展示模型，便于检验错误关联、失效来源和去重。`NativeWorkbenchScreen` 只负责导航与弹层协调，避免继续把所有设置和花瓣逻辑塞进同一个文件。播放器仍由现有模型负责，只允许一个来源发声。

首批不修改共享 Contract、数据库迁移、模型供应商或 ECS 网络规则；接口缺失时显示真实能力边界。如果实施发现当前数据不足以安全映射花瓣，先提出兼容性补充，不能放宽来源或权限判断。

## 7. 分批验收与下一次交接

1. **真实花田**：新录音 → 核对并整理 → 未归组记录出现 → 组织并确认故事 → 花簇 → 花瓣 → 正文与证据 → 原音播放 → 返回原位置。没有已确认故事时也能浏览真实已整理记忆。
2. **设置与账号**：主题切换及重启保留、权限拒绝与重新授权、提醒关闭、缓存清理保留未上传原音、退出换号及迟到响应隔离。
3. **亲友与更新**：分享批准前不可见，批准后出现真实花簇；私密补录不自动出现；明确再次分享后更新；撤权后花田标题、摘要、详情和原音不可继续访问。

确定性测试重点是展示映射与真实 ID、不同故事不会因共用录音被误并、无效来源过滤、跨身份恢复隔离及缓存删除范围，不为静态颜色添加无意义测试。用模拟器实际点击并截图，覆盖浅／深色、360／412 dp、大字号和简化动态效果。

交接包包含新 APK、版本和哈希、真实接口路径说明、按顺序的新增截图、功能采用清单及未通过项。旧 19 张截图保留为旧版本证据，不用新界面覆盖；新截图另外存放并标明版本。截图直接放仓库，无需额外截图网站。

当前 `0.7.1` 下载包继续保留。本版只有在构建和对应手机流程验证后才更新下载与操作说明；更新后端不能代替发布新 APK。实体 Android、新版 iOS及网页完整连续镜头的结果分别列明，不用模拟器结果填写真机通过。

## 8. 设计评审结论

本规格覆盖用户提出的花田、设置、主题、权限和基础账号管理，优先完成真实浏览与控制。密码自助修改和账号注销作为明确的后续接口工作，不把“成品感”理解为堆放尚不可用的功能。设计确认后再编写实施计划与修改客户端；本文件自身不能作为功能通过的证据。
