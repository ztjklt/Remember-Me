# 一层一层，走近记忆 · v15 本地交互

2026-10-02，用户确认 v15 示意方向后授权试做。入口为 `prototype.html?demo=1#archive`，原始分镜保留在 [concepts/garden-depth-v15](concepts/garden-depth-v15/README.md)。本轮只修改网页原型。

## 可以直接体验

1. 花丛：三朵花分别承载厨房、雨夜、凉汤三组相关回忆，共 15 个既有示例片段
2. 花朵：点选的同一朵花从原位置放大，周围枝叶淡出，出现五个花瓣入口
3. 花瓣：选中的瓣形连续延展为暖色阅读底衬，随后显现意象、原话与音频

厨房的第五瓣为不可点击的“待绽放”。雨夜中的“借伞与回应”收纳三个原有片段，展开页连续阅读，不新增第四层。来源、原话及合成音频标记保留；整理导语去掉末尾句号，原稿摘录保持原文。

首页流云、半透明圆角卡片和底栏沿用现有版本。阅读页收起意象管理操作以减少干扰；手机纵向阅读，大屏左侧原话、右侧图片与音频。

## 实现边界

- 花朵继续使用 v14 独立种子的五瓣几何，暴露绘图函数复用；不复制随机形态，进入前后为同一组种子与朝向
- 花朵共享元素 420ms；花瓣取轮廓的 96 个点，按轮廓方向和起点对齐，连续插值至阅读底衬，460ms；返回约 320ms
- 快速返回从当前飞行元素或中间轮廓继续，清理旧动画；周围枝叶 180ms 淡出，文字不随花瓣拉伸
- 缩放/平移、筛选、当前组与每层滚动位置在本次打开中保留；页面按钮、Escape、浏览器返回逐层退回，深层 URL 刷新可恢复相应组/瓣
- 大字号自动改用相同层级的列表；减少动态使用短淡入，不移动或拉伸形状
- 搜索既有原话/标题，筛选情感类别，匹配花瓣以描边提示；图像操作与音频复用已有组件，返回时暂停音频
- 当前三组为手工示例组织，不代表自动聚类或服务端分类已实现
- 增长模型每屏最多三朵，每朵最多五瓣；未知新增片段保持独立，溢出生成后续花朵，现有组/瓣 ID 不变。正式多用户存储、语义合组、真实大规模性能仍待验证

本轮未修改 Android / iOS、Backend、AI Core 或共享 Contract。图片仍是预生成意象，音频仍是虚构故事的合成 MP3；没有新增录音、实时生图或真实模型能力。未提交、推送或发布。

## 本次验证

`node --test docs/mobile-ui/memory-garden/depth.test.cjs docs/mobile-ui/memory-garden/garden.test.cjs docs/mobile-ui/memory-garden/imagery.test.cjs`：16/16 通过。新增三个检查先失败后通过：所有片段唯一归属、追加 302 条后原有分类稳定且可分页、空瓣/跨组非法进入与逐层返回。302 条是纯模型测试数据，没有放入演示页面。

浏览器实际检查：

- 花丛 → 厨房 → 妈妈的小本子 → 两次返回；雨夜一瓣的三个摘录均可见
- 播放合成 MP3、启用循环、离开后 `paused=true`
- 125% 缩放进入，再用浏览器逐层返回，仍为 125%
- 连续进入/快速返回后无残留飞行层、无隐藏花瓣、无重复 DOM ID；检查时未发现控制台错误
- 搜索“便条”显示一个匹配片段，进入雨夜后“借伞与回应”花瓣高亮
- 默认手机内容框 390×844；窄屏实测 358×843，触控标签约 48px 高，无横向溢出。浏览器视口覆盖值与 DOM 逻辑像素不同，以上记录实测值
- 深色 + 200% 文字 + 减少动态路径可用，无横向溢出、无飞行层；宽屏 1645px 下双栏和图片正常

Windows 浏览器验收不等于 Android / iOS 真机验收。双指触控、设备返回手势及持续帧率仍需在实际手机测试；本轮验证了按钮/键盘缩放、返回与已有双指几何单元测试。
