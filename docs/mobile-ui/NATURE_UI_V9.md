# 清晰，也从容 · 本地第九轮

2026-10-02。根据用户提供的浮动底栏与清晰列表参考，在 `codex/nature-mobile-ui` 延续自然风景方向。修改仍留在本地，未提交、推送或发布。

## 这轮变化

- 浮动胶囊底栏：深浅色都有明确的实色选中块，图标和文字一起改变颜色、字重；选中块滑动到目标位置。网页底栏节点与 Android 底栏常驻，切页时不再重建。
- 网页页面过渡：正文轻移并淡入，风景交叉淡化；底栏始终可见。连续点击会清理上一次的过渡层。临时画面不可交互、对读屏隐藏，并移除重复 ID。
- 档案分栏：录音 / 记忆使用胶囊选中态；网页分栏切换保留搜索输入和焦点，支持方向键、Home / End。浏览页面往返保留网页滚动位置与搜索条件，Android 用 SaveableStateHolder 保留目的地内的可保存状态。
- 阅读层级：操作界面的标题、列表标题使用较清楚的无衬线字重，首页和录音的邀请文案保留衬线字体；时间独立成行，状态使用图标、文字和底色组合。待核对使用暖琥珀色，已整理使用绿色，原生失败状态保留错误色。
- 保留草地、湖畔、林间与海边背景；无持续漂浮或装饰循环。减少动态时网页跳过页面过渡并关闭 CSS 动效，iOS 读取系统减少动态设置，Compose 动画使用系统时长缩放。

## 平台实现与边界

| 实现 | 本次内容 |
| --- | --- |
| 网页示例 | Android 模式沿用今天 / 档案 / 我的，iOS 模式有对话入口。底栏滑动 380 ms，正文进入 280 ms、离开 180 ms，风景淡化 340 ms。仍为固定资料，不采集或发送声音。 |
| Android Compose | 保留当前今天 / 图谱 / 档案 / 助手 / 我的五个入口；常驻底栏滑动 320 ms，浏览页 AnimatedContent 过渡，档案分栏与处理状态标签同步。录音与详情在浏览动效容器之外，避免为动画创建两个录音页面。 |
| iOS SwiftUI | 保留四个原生 TabView / NavigationStack 与各自导航状态，增加浮动底栏及 matchedGeometryEffect 选中块；档案内容淡入淡出，录音列表增加状态标签。没有替换原生导航栈或服务模型。 |

iOS 本轮主要动画为底栏及档案分栏，没有用自建页面容器替换 TabView 的系统切页行为。网页与原生 Android 的入口数量沿用各自现有范围，网页不是 Android 原生画面的逐项复刻。

## 本次实际验证

- Android：离线执行 `gradle -p apps/android test assembleDebug --offline --console=plain`，构建成功；Debug / Release 各 18 项现有单元测试，0 失败。日志：`output/playwright/android-build-v9.log`。
- 网页：通过当前内置浏览器检查底栏连续切换、档案搜索及分栏保留、键盘切换、减少动态。模拟录音授权 → 暂停 / 继续 → 保存 → 模拟转写 → 编辑并保存核对文字 → 整理授权 → 记忆 → 返回档案通过。浏览器捕获的 warning / error 日志为空。
- 布局：读取同一浏览器会话的实际 CSS 视口。359 × 800 检查 Android / iOS 导航、浅色与深色 200% 字号及减少动态；430 × 841 检查 iOS 浅色档案。检查到的页面无横向溢出，底栏在视口内；359 宽大字导航按钮最小宽度约 80 px，430 宽普通导航最小触控尺寸约 58 px。没有把工具请求的尺寸误当作实际尺寸。
- 对比度：新状态标签的前景 / 实色背景均超过 5.6:1，深浅色选中导航均超过 7.6:1。详见 `contrast-verification.json`；这不是对风景全部像素的自动审核。
- `node --check` 检查外部导航脚本和提取的内联脚本；`git diff --check` 通过。iOS Asset Catalog JSON 可解析。
- [当前档案页截图](media/nature-v9-archive.jpg) 来自网页预览，不是原生设备截图。之前的 v8 56 组检查保留为历史结果，本轮没有冒称重新运行全套。

Windows 环境未编译 iOS，Android / iOS 本轮均未完成设备视觉与动效验收。构建及网页验证不能替代真实手机的流畅度、读屏或触控检查。
