# Product Requirements

The approved product baseline is [Remember Me PRD v2.0](Remember_Me_PRD_v2.0.docx). Coding agents should use [PRD v2.0 Summary](PRD_V2_SUMMARY.md) for fast orientation and consult the source document for full requirements, tables, definitions, risks, and acceptance criteria.

Team ownership and contract decisions implement the PRD but do not replace it. When implementation guidance conflicts with the PRD, open an Issue and obtain a Product and Integration Owner decision before changing shared architecture or contracts.

The PRD describes an iOS and SwiftUI client in its architecture section, while the current approved execution baseline continues the existing Android prototype. Android remains the active competition client until the Product and Integration Owner explicitly changes the platform decision.
