# Remember Me Design System

视觉方向是温暖、安静、人本、编辑感、记忆与时间。它更接近日记、声音档案和人生书籍，而不是 AI Dashboard。

`RememberMeColors` 使用纸张般的暖白背景、深炭正文、暖灰次要文字、克制的苔绿与陶土色。`RememberMeTypography` 由 Material Typography 在 Theme 中定义：大标题采用系统 Serif，持续阅读使用可靠的系统 Sans。`RememberMeSpacing` 和 `RememberMeShapes` 提供统一尺度。

核心组件包括页面容器、主次按钮、Section Header、Capture Orb、Waveform、Voice Player 与 Divider。页面通过留白、字体和细分隔线建立层级，避免把所有内容装进大圆角卡片。动画只用于呼吸、波形、处理反馈与状态变化。

## 本地模式页面基线

目标语言为中文。模型名、协议名、来源 ID 等技术标识保留原名；主要动作和状态使用中文。
本地设置、处理、录音库及共同 Agent 页面文案收在 `res/values/strings.xml`。其他旧 Demo/远程页面的完整外置不属于本轮。

| 页面 | 信息层级与操作 |
| --- | --- |
| 模型设置 | 先解释数据去向，再分语音/文字配置；密钥遮罩；处理同意后才能测试/保存 |
| 每日提醒 | 设置页默认关闭；先获通知许可再启用；本机时间可编辑，不承诺精确后台送达 |
| 画像与记忆关联 | 先当前版本与关联预览，再完整领域结论和证据展开，最后心理候选与回到问答校正；区分原文与本人校正 |
| 确认录音 | 日期、时长、处理说明；主要动作“开始转写并更新理解”，次要动作模型设置 |
| 处理状态 | 标题严格对应结果，错误可重试，暂停可继续/取消；真实成功才显示“处理完成” |
| 原文与理解 | 四个区段顺序固定；历史/证据/调试折叠；旧锁定回答保留，本人校正独立展示 |
| 我录过的 | 录音状态、原文、播放/处理/删除；版本历史折叠；全部清除放底部并二次确认 |

删除确认明确清除范围和不可撤销性；删除/撤除记录继续显示状态，失效回答不展示已撤除内容。
本地不显示未实现的 trait 支持/冲突标签；电脑模式保留既有状态语义。
心理习惯标为单次观察或多来源候选，保留具体情境和限制，不展示人格完成度、模型估计百分比或诊断标签。
不要用固定人物信息代替真实资料；Demo 页面必须明确标注，不能自动接在首次真实录音后。
