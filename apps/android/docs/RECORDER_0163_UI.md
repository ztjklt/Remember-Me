# 0.16.3 录音界面与动效

本次只调整 Android 表现层，沿用现有连接、设备标记、自动转写、确认文字和生成记忆流程。

- 记忆完成卡只显示状态、第一条真实记忆的两行加粗预览、查看入口。整张卡可点击，完整内容保留在详情。
- 录音豆弹窗按内容确定高度。产品展示参考用户提供的 JPG，以内置图像编辑工具生成透明背景产品示意素材；原图另行保留。轻微上下悬浮和透视倾斜是 Compose 图层动画，并非可交互的三维模型。
- 用户追加的官方 App 截图用于布局参考：统一绿色渐变背景、绿色搜索光圈、产品缩略图和设备选择卡。扫描列表的标识来自 SDK 的 MAC 尾号，不将它误写成官方截图中的 SN，也不复制示例设备或连接状态。
- 产品图仅在设备弹窗显示；简易模式或系统关闭动画时保持静止。动画在绘制层读取状态，不要求整页每帧重排。
- 设备录音、手机原音、设备设置和连接帮助分别按需展开。设置与诊断能力保留，不在首页展开。
- 同步、转换、上传使用已有回调百分比，平滑过渡到已收到的数值。未知进度仅显示当前操作，不显示循环条，也不补造百分比。
- 转写显示「流程 50%」：原音已保存，文字尚未返回。保存文字后重新进入记忆流程：保存完成为 33%，提取完成并开始整理为 67%，服务端 ready 后显示完成卡。它表示已完成流程步骤，不是模型耗时或剩余时间比例。服务端未推进时数值保持不动，不按时间虚增。

产品图来源：用户在本次 UI 反馈中提供的 soundcore Work 产品图，原文件 SHA256 见验收材料。抠图提示要点：保留录音豆、充电盒外观与透视，仅去除白底、输出透明 PNG，并清理深绿色背景上的边缘。工具为内置 image_gen。截图和录屏来自模拟器；电量及蓝牙事件由测试替身提供，不代表实物读数。云端验收另以虚构音频执行。
