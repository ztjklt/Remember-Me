# 手机独立 Agent（1.2-local）

本模式借鉴 Memex 的本地存储、供应商适配及持久任务执行结构，使用一个文字模型。
录音 → 转写 → 理解 → 提问 → 保存回答 → 本人校正 → 更新理解，全部由 Android 编排。
模型推理仍在供应商服务器执行，需要网络；无需电脑 Backend、USB、ADB 或无线调试。

## 安装与配置

1. 把 `build/releases/remember-me-1.2-local-debug.apk` 传到手机，在文件管理器中安装更新。
   同签名可覆盖安装；无需卸载旧版。不要为安装清除数据。编译命令仅供开发者使用。
2. 进入录音页，确认显示“手机独立模式”，点“模型设置”。不需要 Actor/Subject/Consent ID。
3. 分别填写两套配置。当前已验证：

   | 配置 | 协议 | Base URL | Model |
   | --- | --- | --- | --- |
   | 语音 | DashScope 原生 | 当前阿里云服务根地址，去掉 `/compatible-mode/v1` | `qwen-audio-3.0-asr-flash` |
   | 文字 | OpenAI-compatible | `https://api.deepseek.com` | `deepseek-flash` |

   语音服务若使用专属工作空间域名，就填写该域名，不用页面默认公共地址。
   两个 Key 分别填写对应供应商的 Key；APK 不预置。原生 ASR 路径由适配器添加。
4. 阅读并勾选处理同意，测试文字模型，保存配置。可先录音，再回设置“用最新录音测试语音模型”。
   Key 以 Android Keystore 加密保存，排除系统备份。未保存的配置草稿不会跨进程保留。

## 验证一次循环

1. 录音并保存，进入处理页，点“开始转写并更新理解”。首次请求可能需要等待。
2. 查看原文和当前理解，提问“我有几个队友，他们分别是什么专业？”。答案只应依据录音。
3. 再问姓名，在“本人的校正”填写正确姓名，保存并更新，再次提问确认。旧回答保留用于比较。
4. 关闭并重开 App，在录音页点“查看已有录音与理解”，检查原文、理解和上次回答/校正。
5. 断网请求应显示失败。恢复网络后点“继续任务”，沿已保存的阶段继续，不重复成功的转写。

处理中保持应用打开。任务会落库，但没有保证锁屏或进程终止后自动后台完成；重启后需显式继续。
限制：单段 ≤5 分钟、≤7.5 MB，传给文字模型的 JSON 输入 ≤60,000 字符。超限明确失败，不压缩或截断原文。
电脑资料仍在电脑，当前没有自动导入；录音页可切回电脑模式。卸载/清除应用数据会删除手机资料。

构建及已执行检查见 [验证记录](../../../docs/verification/ANDROID_LOCAL_2026_10_07.md)。

## 留存与删除

录音页“我录过的”列出本机音频与已处理/撤除/删除状态，可播放、处理、删除；理解版本历史在同页查看。
不自动清理录音或版本，不做内容压缩。由用户主动删除；撤除只停止 Agent 使用，删除还清除音频、sidecar、原文及依赖校正/旧版本内容。
保留不含内容的来源 ID 和失效记录。文件删除失败显示待重试；再次删除即可继续，失效材料不会重新进入回答。
“清除本地数据并退出手机模式”需确认，将删除所有本机录音、日志和加密模型配置；不删除电脑副本。
