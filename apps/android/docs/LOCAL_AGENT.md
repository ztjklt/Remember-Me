# 手机独立 Agent（1.4-local）

本模式借鉴 Memex 的本地存储、供应商适配及持久任务执行结构，使用一个文字模型。
录音 → 转写 → 画像提取 → 心理候选分析 → 发布理解 → 提问 → 保存回答 → 本人校正 → 更新理解，全部由 Android 顺序编排。
模型推理仍在供应商服务器执行，需要网络；无需电脑 Backend、USB、ADB 或无线调试。

## 安装与配置

1. 把 `build/releases/remember-me-1.4-local-debug.apk` 传到手机，在文件管理器中安装更新。
   同签名可覆盖安装；无需卸载旧版。不要为安装清除数据。编译命令仅供开发者使用。
2. 进入录音页，确认显示“手机独立模式”，点“模型设置”。不需要 Actor/Subject/Consent ID。
3. 分别填写两套配置。当前已验证：

   | 配置 | 协议 | Base URL | Model |
   | --- | --- | --- | --- |
   | 语音 | DashScope 原生 | 当前阿里云服务根地址，去掉 `/compatible-mode/v1` | `qwen-audio-3.0-asr-flash` |
   | 文字 | OpenAI-compatible | `https://api.deepseek.com` | `deepseek-flash` |

   语音服务若使用专属工作空间域名，就填写该域名，不用页面默认公共地址。
   两个 Key 分别填写对应供应商的 Key；APK 不预置。原生 ASR 路径由适配器添加。
4. 阅读并勾选处理同意，测试文字模型，保存配置。可先录音，再回设置“用最新录音测试语音模型”。
   Key 以 Android Keystore 加密保存，排除系统备份。未保存的配置草稿不会跨进程保留。

## 验证一次循环

1. 录音并保存，进入处理页，点“开始转写并更新理解”。首次请求可能需要等待。
2. 查看原文和当前理解，提问“我有几个队友，他们分别是什么专业？”。答案只应依据录音。
3. 再问姓名，在“本人的校正”填写正确姓名，保存并更新，再次提问确认。旧回答保留用于比较。
4. 关闭并重开 App，在录音页点“查看已有录音与理解”，检查原文、理解和上次回答/校正。
5. 断网请求应显示失败。恢复网络后点“继续任务”，沿已保存的阶段继续，不重复成功的转写。

处理中保持应用打开。任务会落库，但没有保证锁屏或进程终止后自动后台完成；重启后需显式继续。
限制：单段 ≤5 分钟、≤7.5 MB，传给文字模型的 JSON 输入 ≤60,000 字符。超限明确失败，不压缩或截断原文。
电脑资料仍在电脑，当前没有自动导入；录音页可切回电脑模式。卸载/清除应用数据会删除手机资料。

构建及已执行检查见 [验证记录](../../../docs/verification/ANDROID_LOCAL_2026_10_07.md)。
本轮稳定性修复与验收边界见 [本地 Agent 加固记录](../../../docs/reviews/local-agent-hardening/README.md)。

## 三个数字孪生业务角色

- Memory keeper：模型设置页自愿开启每日录音提醒，填写本机时间 `HH:mm` 并保存。允许通知后每天提醒一次，点通知打开 App，由你选择是否录音；可随时关闭。省电策略可能延迟通知。
- Portrait reader：进入“记忆与理解 → 查看我的画像与记忆关联”，查看当前版本的七领域画像、关联图和可展开原文/校正。每条结论能连接多份证据；图仅有限预览，列表保留全部关联。
- Psychological learner：录下具体经历，例如压力情境、你的反应和应对方式。更新理解时同一文字模型在画像步骤之后分析心理习惯候选；身份、专业等普通事实可以没有候选。一次观察不代表固定性格，重复同一段文字不算独立印证。进入画像页查看候选及原文，在原问答循环中校正后再次查看。

旧资料可直接读取；新增录音或本人校正时才运行新分析，不在升级后自动发送历史原文。心理候选参与相关行为推演，但仍需原文证据，不是疾病诊断，也不是模型权重训练。
新步骤失败不发布半完成版本；成功的 ASR 和画像有检查点，点击继续任务复用。撤除/删除来源后相关候选从展示及回答排除。
三个角色属于手机独立模式；电脑模式保持原行为。“八大记忆/四大画像”未定义分类表，本轮未修改 shared 枚举。
本轮测试、设备未执行项与回滚影响见 [角色验证记录](../../../docs/verification/ANDROID_TWIN_ROLES_2026_10_07.md)。

## 实验开关与评审

本安装包是 Debug，默认手机独立模式，可切换电脑模式；本地主要操作文案使用中文。
release 构建关闭 `BuildConfig.LOCAL_AGENT_ENABLED`，使用电脑模式，不加载本地日志或密钥。
已有本地资料不会因此删除；继续使用本地资料请安装同签名的 Debug 更新包。
Backend 的 `REMEMBER_AGENT_ENABLED` 默认 false，是独立的服务端实验开关。
BYOK 为用户授权的实验实现，仍待 Product/Integration 追认；合并前须张天霁及相关 owner review。

## 留存与删除

录音页“我录过的”列出本机音频与已处理/撤除/删除状态，可播放、处理、删除；理解版本历史在同页查看。
不自动清理录音或版本，不做内容压缩。由用户主动删除；撤除只停止 Agent 使用，删除还清除音频、sidecar、原文及依赖校正/旧版本内容。
保留不含内容的来源 ID 和失效记录。文件删除失败显示待重试；再次删除即可继续，失效材料不会重新进入回答。
“清除本地数据并退出手机模式”需确认，将删除所有本机录音、日志和加密模型配置；不删除电脑副本。

## 中断、容量与版本恢复

转写完成后取消理解，原文仍进入归档和问答；录音库标记“待理解”，再次处理复用转写，不重复调用 ASR。
超过 60,000 字符会提示删除较长原文；可在保留待处理录音任务的同时删除旧录音，再点“继续任务”。不提供自动检索、摘要截断或压缩。
本地只展示理解内容，不展示尚未实现连续性语义的 trait 状态标签；撤除来源后的相关理解被排除。
数据库迁移先在 no-backup 私有目录保存原始 payload；未知版本保留数据并提示升级，可经系统文件选择器导出可读原文。
恢复导出只投影来源和原文，不读取模型配置。原始恢复文件不自动备份或导出；明确删除录音/清空数据时也清除旧恢复副本。

## 八维观察（本地实验）

本地 journal 增加 `observations`，不更改共享 Memory 枚举或 experimental 契约版本。
`MemoryDimensionRegistry` 定义事件、情绪、心理、滤镜、状态、环境、身份 IP、表达；
单个主模型按片段提取，不为八类分别创建 Agent。每条观察保留连续原文引用、Unicode
码点偏移（末端不包含）、来源和模型/提示词/分类版本。身份属性分别记录；无依据的维度允许空。
状态和环境目前只接受本人自述，音频状态/背景音检测未实现。

ASR 成功就将原文写入既有 SQLite journal，独立于观察和画像阶段；派生阶段失败可继续，
不重新调用 ASR。在画像待重试时仍可问原文问题。`memory_revision` 表示材料版本，
`revision` 表示已发布人物理解版本；提交校正同时检查两者，防止引用过期材料。
画像状态为 PENDING/BUILDING/READY/FAILED，不能用录音成功掩盖画像失败。
长原文分成完整片段逐批提取并保存偏移检查点，未压缩或丢弃字符。
删除清除依赖观察；撤除的来源不能进入任何观察投影。

## 增量理解与检索

文字理解只提交本次片段及相关旧证据，代码保留未涉及的旧属性。同义事实复用 trait ID；
本人纠错替换该属性，支持追加引用，真正变化新建属性并在版本历史中保留旧状态。
心理分析使用相关观察/已有候选来源，提问不写入本人业务记忆。

本地使用兼容 Android 平台的中文双字/英文词索引，不依赖未经真机确认的 FTS5。
检索完整片段，保留父证据 ID 与 Unicode 码点 span；校正和其依赖一起召回，删除/撤除沿父来源失效回答。
枚举匹配结果不取固定 top-k；仍须由模型区分已知名单与完整名单。中文字符召回不是语义检索，
没有匹配时小型旧资料完整兜底，大型历史需更明确问题；相关材料超容量会说明并保留原文。

文字 HTTP 适配器支持可选 `reasoning_effort`。已知 DeepSeek 端点默认普通模式；其他端点不自动发送该字段。
用户可在设置中选择，服务必须支持该参数。输出上限为 8192 tokens，拒绝 `finish_reason=length`；
不记录/展示 reasoning_content 或供应商错误正文。依据：[官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 四类画像数据

`PortraitViews` 从授权、未撤除、未被替代的观察生成事件、情绪、决策与表达投影。
事件区分已发生/计划/愿望及未知日期；回忆情绪没有事件日期时不使用录音日期。
决策的选项、选择、理由和价值必须由原文明确给出；偏好不自动成为决策。
表达样本按不同原文计数，重复转写不成为独立样本，未接入声学语速/停顿检测。

观察校正只允许引用相关原文的同维度观察，身份还必须同 facet；被替代观察保留来源并退出四图。
单个事件纠错没有重述日期时沿用被替代事件的有据日期，记录 `time_inherited_from`。
删除继续沿校正的原文依赖级联；失效源和被替代观察都不能重新进入视图。

旧 APK 数据使用原 SQLite journal 的附加字段，可读、可继续问答；不会卸载、自动转移资料或再调用 ASR。
显式“重新提取已有记忆”依次处理现有授权原文和校正，队列/阶段可恢复；取消保留已完成观察和所有原文。
电脑模式只投影其已有七领域快照，不凭空制造八维服务端数据；扩展服务端契约仍待 owner 评审。
